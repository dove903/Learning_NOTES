## 15.1 氧族元素的通性

氧族元素位于周期表第六主族，价层电子构型 $ns^2np^4$，包括氧（O）、硫（S）、硒（Se）、碲（Te）、钋（Po）五种元素。

### 一、存在

- **氧**：地球表面丰度最大的元素，以单质和化合态形式存在
- **硫**：天然气中的 $\ce{H2S}$、原油和煤中的有机硫、硫铁矿、金属硫化物矿及硫酸盐
- **硒和碲**：存在于金属硫化物矿中
- **钋**：人工合成

### 二、基本性质

| 性质 | 趋势 |
|------|------|
| 原子半径、离子半径 | 从氧到钋逐渐增大 |
| 第一电离能、电负性 | 从氧到钋依次减小 |
| 金属性 | 从氧到钋逐渐增强 |
| 非金属性 | 从氧到钋逐渐减弱 |
| 氧化值 | O: (0, -1, -2, +2)；S: (0, -2, +4, +6)；Se, Te: (0, -2, +2, +4, +6) |

S、Se、Te 与其他元素化合时形成**共价化合物**，与氧化合时生成 $\ce{RO2}$、$\ce{RO3}$ 酸性氧化物，其中有配位键形成。

## 15.2 氧及其化合物

### 一、氧气单质

#### 1. 结构
氧分子轨道电子排布式：键级 = 2，一个 $\sigma$ 键，两个三电子 $\pi$ 键，具有**顺磁性**。

#### 2. 性质
- 常温下仅能使一些还原性强的物质（如 NO、$\ce{SnCl2}$、$\ce{KI}$ 等）氧化
- 加热条件下，除 $\ce{X2}$、Au、Pt 及稀有气体外，$\ce{O2}$ 几乎能与所有元素直接化合
- 氧能与许多低氧化值氧化物反应生成高氧化态物质
- 可与硫化物反应生成氧化物或硫酸盐

#### 3. 用途
高能燃料、火箭推进剂助燃剂、气焊切割、输氧

### 二、氧化物

#### 按酸碱性分类

| 类型 | 说明 | 实例 |
|------|------|------|
| 酸性氧化物 | 大多数非金属氧化物 + 高氧化值金属氧化物 | $\ce{SO3}$、$\ce{Cl2O7}$ |
| 碱性氧化物 | 大多数金属氧化物 | $\ce{Na2O}$、$\ce{MgO}$ |
| 两性氧化物 | 部分金属氧化物 + 少数非金属氧化物 | $\ce{Al2O3}$、$\ce{As4O6}$ |
| 中性氧化物 | — | $\ce{NO}$、$\ce{CO}$ |

#### 酸碱性一般规律
- 同周期最高氧化态氧化物：从左到右 碱性 → 两性 → 酸性
  $$\ce{Na2O → MgO → Al2O3 → SiO2 → P4O10 → SO3 → Cl2O7}$$
- 同族相同氧化态氧化物：从上到下碱性增强
  $$\ce{N2O3 → P4O6 → As4O6 → Sb4O6 → Bi2O3}$$
- 同一元素不同氧化态：酸性随氧化数升高而增强
  例：$\ce{PbO}$（碱性）、$\ce{PbO2}$（两性）

### 三、臭氧

臭氧和氧互为**同素异形体**，集中在离地面 20~40 km 的同温层中，吸收太阳光的紫外辐射。
- $\ce{CFCl3}$、$\ce{CF2Cl2}$ 和氮氧化合物破坏臭氧层

#### 1. 结构
臭氧分子无单电子，为**反磁性**物质。

#### 2. 性质
- 淡蓝色气体，有鱼腥臭味，161 K 为深蓝色液体
- 唯一有极性的单质分子，比 $\ce{O2}$ 易溶于水
- 不稳定性：$\ce{2O3 -> 3O2}$，$\Delta_r H_m^\theta = -286\ \text{kJ/mol}$

#### $\ce{O3}$ 和 $\ce{O2}$ 对比

| 性质 | $\ce{O3}$ | $\ce{O2}$ |
|------|-----------|-----------|
| 键角 | 116.8° | 180° |
| 键长 / pm | 127.8 | 120.8 |
| 键级 | 1.5 | 2 |
| 键能 | 小 | 大 |
| 磁性 | 抗磁性 | 顺磁性 |

#### 化学性质
- **强氧化剂**：$\ce{PbS + 4O3 -> PbSO4 + 4O2}$
- 鉴定臭氧：$\ce{2I- + O3 + H2O -> I2 + O2 + 2OH-}$
- 用途：环保（氰化物、酚解毒）、饮用水消毒

### 四、过氧化氢

#### 1. 制备和用途
- 实验室：$\ce{BaO2 + H2SO4 -> BaSO4↓ + H2O2}$
- 工业：电解法，$(NH4)2S2O8 + 2H2O -> 2NH4HSO4 + H2O2$
- 用途：3% 消毒、氧化剂和漂白剂

#### 2. 结构
$\ce{H2O2}$ 中 $\angle\ce{HOO} = 94°$，$\angle\ce{OOH}$（二面角）$= 97°$，$\ce{O-O}$ 键长 148 pm。

#### 3. 性质

**（1）不稳定性**
$$\ce{2H2O2 -> 2H2O + O2↑}\quad \Delta_r H_m^\theta = -198\ \text{kJ/mol}$$
光照、碱性介质、重金属能加快分解。应装入棕色瓶或塑料瓶，阴凉处保存。

**（2）弱酸性（二元弱酸）**
$$\ce{H2O2 <=> H+ + HO2-}\quad K_{a1} = 2.2 × 10^{-12}$$
$$\ce{HO2- <=> H+ + O2^{2-}}\quad K_{a2} = 1.0 × 10^{-25}$$

**（3）氧化还原性**
- 过氧化氢的氧化性较还原性突出
- 酸性介质中氧化性强于碱性介质
- 只有遇到强氧化剂时才体现还原性

**作为氧化剂**：
$$\ce{H2O2 + 2I- + 2H+ -> 2H2O + I2}$$
$$\ce{PbS + 4H2O2 -> PbSO4↓ + 4H2O}$$

**作为还原剂**：
$$\ce{5H2O2 + 2MnO4- + 6H+ -> 5O2↑ + 2Mn^{2+} + 8H2O}$$
$$\ce{H2O2 + Cl2 -> 2HCl + O2↑}$$

主要优点：不会给反应体系引入杂质。

## 15.3 硫及其化合物

### 一、硫的同素异形体

| 性质 | 斜方硫 | 单斜硫 | 弹性硫 |
|------|--------|--------|--------|
| 密度 / g·cm⁻³ | 2.06 | 1.99 | — |
| 颜色 | 黄色 | 浅黄色 | — |
| 稳定性 | < 94.5℃ | > 94.5℃ | 190℃熔融硫用冷水速冷 |

- 结构：$\ce{S}$ 为 $sp^3$ 杂化，形成环状 $\ce{S8}$ 分子
- $\ce{S8}$ 分子为分子晶体，不溶于水，溶于 $\ce{CS2}$

### 二、硫化物和多硫化物

#### 1. 硫化氢和氢硫酸
- 结构：与 $\ce{H2O}$ 相似呈 V 型，键长 $\ce{H-S > H-O}$，键角 $\ce{H2S < H2O}$
- 制备：$\ce{FeS + 2H+ -> Fe^{2+} + H2S↑}$
- 硫代乙酰胺可代替 $\ce{H2S}$ 作沉淀剂

**化学性质**：
- 氢硫酸为**二元弱酸**
- $\ce{H2S}$ 具有**还原性**：
  $$\ce{2H2S + 3O2(足) -> 2SO2↑ + 2H2O}$$
  $$\ce{2H2S + O2(不足) -> 2S + 2H2O}$$
- $\ce{S^{2-}}$ 易被氧化为单质硫，在碱性介质中还原性比酸性中强
- 强氧化剂可使 $\ce{S^{2-}}$ 氧化为硫酸
- $\ce{H2S}$ 可作沉淀剂

#### 2. 金属硫化物
- 酸式盐都易溶于水
- 正盐中 IA、$(NH4)2S$ 和 $\ce{BaS}$ 易溶，其余微溶或难溶

**颜色**（需特殊记忆）：
| 硫化物 | 颜色 |
|--------|------|
| $\ce{SnS}$ | 棕 |
| $\ce{SnS2}$ | 黄 |
| $\ce{As2S3}$ | 黄 |
| $\ce{Sb2S3}$ | 橙 |
| $\ce{MnS}$ | 肉色 |
| $\ce{ZnS}$ | 白 |
| $\ce{CdS}$ | 黄 |

**水解性**：$\ce{Al2S3}$、$\ce{Cr2S3}$ 在水溶液中不存在（强烈水解）

#### 3. 多硫化物
- 制备：$\ce{S^{2-} + (x-1)S -> S_x^{2-}}$
- 随 x 增加，颜色从黄 → 橙黄 → 红
- **氧化还原性**：$\ce{SnS + S2^{2-} -> SnS3^{2-}}$
- 酸性溶液中不稳定（歧化）：$\ce{S2^{2-} + 2H+ -> H2S2 -> H2S + S}$

### 三、硫的含氧化合物

| 名称 | 化学式 | 硫的氧化态 |
|------|--------|-----------|
| 次硫酸 | $\ce{H2SO2}$ | +2 |
| 连二亚硫酸 | $\ce{H2S2O4}$ | +3 |
| 亚硫酸 | $\ce{H2SO3}$ | +4 |
| 硫酸 | $\ce{H2SO4}$ | +6 |
| 焦硫酸 | $\ce{H2S2O7}$ | +6 |
| 硫代硫酸 | $\ce{H2S2O3}$ | +2 |
| 过一硫酸 | $\ce{H2SO5}$ | +8 |
| 过二硫酸 | $\ce{H2S2O8}$ | +7 |
| 连多硫酸 | $\ce{H2S_xO6}$ (x=2~6) | +5, +3.3, +2.5, +2, +1.7 |

#### 1. 二氧化硫、亚硫酸及其盐

**二氧化硫**：无色有刺激气味，极性很强，易溶于水，是很好的非水溶剂。
- 化学性质：氧化还原性（还原性较显著）、漂白性

**亚硫酸（二元中强酸）**：
$$\ce{SO2 + H2O <=> H+ + HSO3- <=> 2H+ + SO3^{2-}}$$
- 不稳定性
- 还原性较突出（$\ce{H2SO3 + O2 -> H2SO4}$）
- 在较强还原剂作用下表现出氧化性：$\ce{H2SO3 + 2H2S -> 3S↓ + 3H2O}$

**亚硫酸盐**：
- 绝大多数正盐（$\ce{K+}$、$\ce{Na+}$、$\ce{NH4+}$ 除外）不溶于水，酸式盐多溶于水
- 热稳定性差：$\ce{4Na2SO3 -> 3Na2SO4 + Na2S}$（加热）
- $\ce{SO3^{2-} + 2H+ -> SO2↑ + H2O}$（鉴定 $\ce{SO3^{2-}}$）
- 除氯剂：$\ce{SO3^{2-} + Cl2 + H2O -> SO4^{2-} + 2Cl- + 2H+}$
- 保险粉 $\ce{Na2S2O4}$：强还原剂

#### 2. 三氧化硫、硫酸及其盐

**三氧化硫**：
- 强氧化剂：$\ce{5SO3 + 2P -> 5SO2 + P2O5}$
- 强吸水性：$\ce{SO3 + H2O -> H2SO4}$

**硫酸**：
- S 采用 $sp^3$ 杂化，分子中除 $\sigma$ 键外，还存在 $(p-d)$ $\pi$ 反馈配键
- 性质：酸性、吸水性、氧化性

**硫酸盐**：
- 正盐难溶：$\ce{BaSO4}$、$\ce{PbSO4}$、$\ce{CaSO4}$；酸式盐大都溶于水
- $\ce{SO4^{2-}}$ 鉴定：$\ce{Ba^{2+} + SO4^{2-} -> BaSO4↓}$（白色，在 HCl 存在时）

**矾**——带结晶水的过渡金属硫酸盐：
- $\ce{CuSO4·5H2O}$ 蓝矾
- $\ce{FeSO4·7H2O}$ 绿矾
- 通式：$\ce{M^I2SO4·M^{II}SO4·6H2O}$（如摩尔盐 $(NH4)2SO4·FeSO4·6H2O$）
- 明矾：$\ce{K2SO4·Al2(SO4)3·24H2O}$

#### 3. 焦硫酸及其盐
- $\ce{H2S2O7}$：比硫酸具有更强的氧化性、吸水性和腐蚀性
- 焦硫酸盐受热分解：$\ce{K2S2O7 -> K2SO4 + SO3↑}$
- 分析化学中用作熔矿剂

#### 4. 硫代硫酸及其盐
- **硫代硫酸钠**（海波、大苏打）：$\ce{Na2S2O3}$
- 制备：$\ce{Na2SO3 + S -> Na2S2O3}$（煮沸）
- **遇酸分解**：$\ce{S2O3^{2-} + 2H+ -> S↓ + SO2↑ + H2O}$（鉴定反应）
- **还原性**（为主）：
  - 与强氧化剂：$\ce{S2O3^{2-} + 4Cl2 + 5H2O -> 2SO4^{2-} + 8Cl- + 10H+}$（除氯剂）
  - 与较弱氧化剂：$\ce{2S2O3^{2-} + I2 -> S4O6^{2-} + 2I-}$
- **配位能力**：$\ce{AgX + 2S2O3^{2-} -> [Ag(S2O3)2]^{3-} + X-}$
- 重金属硫代硫酸盐不稳定（白色 $\ce{Ag2S2O3}$ 迅速分解为黑色 $\ce{Ag2S}$）

#### 5. 过硫酸及其盐
- 过二硫酸盐：$\ce{Na2S2O8}$ 和 $(NH4)2S2O8$
- **强氧化性**：$\ce{S2O8^{2-} + 2e- -> 2SO4^{2-}}$，$\varphi^\theta = 2.0\ \text{V}$
- $\ce{Mn^{2+} + 5S2O8^{2-} + 8H2O -> 2MnO4- + 10SO4^{2-} + 16H+}$

## 知识要点

1. 氧族元素价层电子构型 $ns^2np^4$，从上到下金属性增强，非金属性减弱
2. 氧气分子键级为 2，有顺磁性；臭氧有反磁性，是强氧化剂
3. 过氧化氢兼具氧化性和还原性，是二元弱酸，不稳定易分解
4. 氧化物酸碱性规律：同周期从左到右碱性→两性→酸性；同族从上到下碱性增强
5. 硫有斜方硫、单斜硫、弹性硫三种同素异形体
6. 硫化氢有较强还原性，可作沉淀剂
7. 亚硫酸以还原性为主，硫酸是强酸、强氧化剂
8. 硫代硫酸钠（海波）：遇酸分解，还原性 $\ce{I2}$ 生成连四硫酸盐，能与 $\ce{Ag+}$ 配位
9. 过硫酸盐是强氧化剂（$\varphi^\theta = 2.0\ \text{V}$）
10. 焦硫酸盐用作熔矿剂，矾是带结晶水的过渡金属硫酸盐
