## 15.1 氧族元素的通性

氧族元素位于周期表第六主族，价层电子构型 $ns^2np^4$，包括氧（O）、硫（S）、硒（Se）、碲（Te）、钋（Po）五种元素。

### 一、存在

- **氧**：地球表面丰度最大的元素，以单质和化合态形式存在
- **硫**：天然气中的 $\mathrm{H_{2}S}$、原油和煤中的有机硫、硫铁矿、金属硫化物矿及硫酸盐
- **硒和碲**：存在于金属硫化物矿中
- **钋**：人工合成

### 二、基本性质

| 性质 | 趋势 |
|------|------|
| 原子半径、离子半径 | 从氧到钋逐渐增大 |
| 第一电离能、电负性 | 从氧到钋依次减小 |
| 金属性 | 从氧到钋逐渐增强 |
| 非金属性 | 从氧到钋逐渐减弱 |
| 氧化值 | O: (0, -1, -2, +2)；S: (0, -2, +4, +6)；Se, Te: (0, -2, +2, +4, +6) |

S、Se、Te 与其他元素化合时形成**共价化合物**，与氧化合时生成 $\mathrm{RO_{2}}$、$\mathrm{RO_{3}}$ 酸性氧化物，其中有配位键形成。

## 15.2 氧及其化合物

### 一、氧气单质

#### 1. 结构
氧分子轨道电子排布式：键级 = 2，一个 $\sigma$ 键，两个三电子 $\pi$ 键，具有**顺磁性**。

#### 2. 性质
- 常温下仅能使一些还原性强的物质（如 NO、$\mathrm{SnCl_{2}}$、$\mathrm{KI}$ 等）氧化
- 加热条件下，除 $\mathrm{X_{2}}$、Au、Pt 及稀有气体外，$\mathrm{O_{2}}$ 几乎能与所有元素直接化合
- 氧能与许多低氧化值氧化物反应生成高氧化态物质
- 可与硫化物反应生成氧化物或硫酸盐

#### 3. 用途
高能燃料、火箭推进剂助燃剂、气焊切割、输氧

### 二、氧化物

#### 按酸碱性分类

| 类型 | 说明 | 实例 |
|------|------|------|
| 酸性氧化物 | 大多数非金属氧化物 + 高氧化值金属氧化物 | $\mathrm{SO_{3}}$、$\mathrm{Cl_{2}O_{7}}$ |
| 碱性氧化物 | 大多数金属氧化物 | $\mathrm{Na_{2}O}$、$\mathrm{MgO}$ |
| 两性氧化物 | 部分金属氧化物 + 少数非金属氧化物 | $\mathrm{Al_{2}O_{3}}$、$\mathrm{As_{4}O_{6}}$ |
| 中性氧化物 | — | $\mathrm{NO}$、$\mathrm{CO}$ |

#### 酸碱性一般规律
- 同周期最高氧化态氧化物：从左到右 碱性 → 两性 → 酸性
  $$\mathrm{Na_{2}O → MgO → Al_{2}O_{3} → SiO_{2} → P_{4}O_{10} → SO_{3} → Cl_{2}O_{7}}$$
- 同族相同氧化态氧化物：从上到下碱性增强
  $$\mathrm{N_{2}O_{3} → P_{4}O_{6} → As_{4}O_{6} → Sb_{4}O_{6} → Bi_{2}O_{3}}$$
- 同一元素不同氧化态：酸性随氧化数升高而增强
  例：$\mathrm{PbO}$（碱性）、$\mathrm{PbO_{2}}$（两性）

### 三、臭氧

臭氧和氧互为**同素异形体**，集中在离地面 20~40 km 的同温层中，吸收太阳光的紫外辐射。
- $\mathrm{CFCl_{3}}$、$\mathrm{CF_{2}Cl_{2}}$ 和氮氧化合物破坏臭氧层

#### 1. 结构
臭氧分子无单电子，为**反磁性**物质。

#### 2. 性质
- 淡蓝色气体，有鱼腥臭味，161 K 为深蓝色液体
- 唯一有极性的单质分子，比 $\mathrm{O_{2}}$ 易溶于水
- 不稳定性：$\mathrm{2O_{3} \rightarrow 3O_{2}}$，$\Delta_r H_m^\theta = -286\ \text{kJ/mol}$

#### $\mathrm{O_{3}}$ 和 $\mathrm{O_{2}}$ 对比

| 性质 | $\mathrm{O_{3}}$ | $\mathrm{O_{2}}$ |
|------|-----------|-----------|
| 键角 | 116.8° | 180° |
| 键长 / pm | 127.8 | 120.8 |
| 键级 | 1.5 | 2 |
| 键能 | 小 | 大 |
| 磁性 | 抗磁性 | 顺磁性 |

#### 化学性质
- **强氧化剂**：$\mathrm{PbS + 4O_{3} \rightarrow PbSO_{4} + 4O_{2}}$
- 鉴定臭氧：$\mathrm{2I^{-} + O_{3} + H_{2}O \rightarrow I_{2} + O_{2} + 2OH^{-}}$
- 用途：环保（氰化物、酚解毒）、饮用水消毒

### 四、过氧化氢

#### 1. 制备和用途
- 实验室：$\mathrm{BaO_{2} + H_{2}SO_{4} \rightarrow BaSO_{4}\downarrow + H_{2}O_{2}}$
- 工业：电解法，$(NH_{4})_{2}S_{2}O_{8} + 2H_{2}O -> 2NH_{4}HSO_{4} + H_{2}O_{2}$
- 用途：3% 消毒、氧化剂和漂白剂

#### 2. 结构
$\mathrm{H_{2}O_{2}}$ 中 $\angle\mathrm{HOO} = 94°$，$\angle\mathrm{OOH}$（二面角）$= 97°$，$\mathrm{O-O}$ 键长 148 pm。

#### 3. 性质

**（1）不稳定性**
$$\mathrm{2H_{2}O_{2} \rightarrow 2H_{2}O + O_{2}\uparrow }\quad \Delta_r H_m^\theta = -198\ \text{kJ/mol}$$
光照、碱性介质、重金属能加快分解。应装入棕色瓶或塑料瓶，阴凉处保存。

**（2）弱酸性（二元弱酸）**
$$\mathrm{H_{2}O_{2} \rightleftharpoons H^{+} + HO_{2}^{-}}\quad K_{a1} = 2.2 × 10^{-12}$$
$$\mathrm{HO_{2}^{-} \rightleftharpoons H^{+} + O_{2}^{2-}}\quad K_{a2} = 1.0 × 10^{-25}$$

**（3）氧化还原性**
- 过氧化氢的氧化性较还原性突出
- 酸性介质中氧化性强于碱性介质
- 只有遇到强氧化剂时才体现还原性

**作为氧化剂**：
$$\mathrm{H_{2}O_{2} + 2I^{-} + 2H^{+} \rightarrow 2H_{2}O + I_{2}}$$
$$\mathrm{PbS + 4H_{2}O_{2} \rightarrow PbSO_{4}\downarrow + 4H_{2}O}$$

**作为还原剂**：
$$\mathrm{5H_{2}O_{2} + 2MnO_{4}^{-} + 6H^{+} \rightarrow 5O_{2}\uparrow + 2Mn^{2+} + 8H_{2}O}$$
$$\mathrm{H_{2}O_{2} + Cl_{2} \rightarrow 2HCl + O_{2}\uparrow }$$

主要优点：不会给反应体系引入杂质。

## 15.3 硫及其化合物

### 一、硫的同素异形体

| 性质 | 斜方硫 | 单斜硫 | 弹性硫 |
|------|--------|--------|--------|
| 密度 / g·cm⁻³ | 2.06 | 1.99 | — |
| 颜色 | 黄色 | 浅黄色 | — |
| 稳定性 | < 94.5℃ | > 94.5℃ | 190℃熔融硫用冷水速冷 |

- 结构：$\mathrm{S}$ 为 $sp^3$ 杂化，形成环状 $\mathrm{S_{8}}$ 分子
- $\mathrm{S_{8}}$ 分子为分子晶体，不溶于水，溶于 $\mathrm{CS_{2}}$

### 二、硫化物和多硫化物

#### 1. 硫化氢和氢硫酸
- 结构：与 $\mathrm{H_{2}O}$ 相似呈 V 型，键长 $\mathrm{H-S > H-O}$，键角 $\mathrm{H_{2}S < H_{2}O}$
- 制备：$\mathrm{FeS + 2H^{+} \rightarrow Fe^{2+} + H_{2}S↑}$
- 硫代乙酰胺可代替 $\mathrm{H_{2}S}$ 作沉淀剂

**化学性质**：
- 氢硫酸为**二元弱酸**
- $\mathrm{H_{2}S}$ 具有**还原性**：
  $$\mathrm{2H_{2}S + 3O_{2}(足) \rightarrow 2SO_{2}\uparrow + 2H_{2}O}$$
  $$\mathrm{2H_{2}S + O_{2}(不足) \rightarrow 2S + 2H_{2}O}$$
- $\mathrm{S^{2-}}$ 易被氧化为单质硫，在碱性介质中还原性比酸性中强
- 强氧化剂可使 $\mathrm{S^{2-}}$ 氧化为硫酸
- $\mathrm{H_{2}S}$ 可作沉淀剂

#### 2. 金属硫化物
- 酸式盐都易溶于水
- 正盐中 IA、$(NH_{4})_{2}S$ 和 $\mathrm{BaS}$ 易溶，其余微溶或难溶

**颜色**（需特殊记忆）：
| 硫化物 | 颜色 |
|--------|------|
| $\mathrm{SnS}$ | 棕 |
| $\mathrm{SnS_{2}}$ | 黄 |
| $\mathrm{As_{2}S_{3}}$ | 黄 |
| $\mathrm{Sb_{2}S_{3}}$ | 橙 |
| $\mathrm{MnS}$ | 肉色 |
| $\mathrm{ZnS}$ | 白 |
| $\mathrm{CdS}$ | 黄 |

**水解性**：$\mathrm{Al_{2}S_{3}}$、$\mathrm{Cr_{2}S_{3}}$ 在水溶液中不存在（强烈水解）

#### 3. 多硫化物
- 制备：$\mathrm{S^{2-} + (x-1)S -> S_x^{2-}}$
- 随 x 增加，颜色从黄 → 橙黄 → 红
- **氧化还原性**：$\mathrm{SnS + S_{2}^{2-} -> SnS_{3}^{2-}}$
- 酸性溶液中不稳定（歧化）：$\mathrm{S_{2}^{2-} + 2H^{+} -> H_{2}S_{2} -> H_{2}S + S}$

### 三、硫的含氧化合物

| 名称 | 化学式 | 硫的氧化态 |
|------|--------|-----------|
| 次硫酸 | $\mathrm{H_{2}SO_{2}}$ | +2 |
| 连二亚硫酸 | $\mathrm{H_{2}S_{2}O_{4}}$ | +3 |
| 亚硫酸 | $\mathrm{H_{2}SO_{3}}$ | +4 |
| 硫酸 | $\mathrm{H_{2}SO_{4}}$ | +6 |
| 焦硫酸 | $\mathrm{H_{2}S_{2}O_{7}}$ | +6 |
| 硫代硫酸 | $\mathrm{H_{2}S_{2}O_{3}}$ | +2 |
| 过一硫酸 | $\mathrm{H_{2}SO_{5}}$ | +8 |
| 过二硫酸 | $\mathrm{H_{2}S_{2}O_{8}}$ | +7 |
| 连多硫酸 | $\mathrm{H_{2}S_xO_{6}}$ (x=2~6) | +5, +3.3, +2.5, +2, +1.7 |

#### 1. 二氧化硫、亚硫酸及其盐

**二氧化硫**：无色有刺激气味，极性很强，易溶于水，是很好的非水溶剂。
- 化学性质：氧化还原性（还原性较显著）、漂白性

**亚硫酸（二元中强酸）**：
$$\mathrm{SO_{2} + H_{2}O \rightleftharpoons H^{+} + HSO_{3}^{-} \rightleftharpoons 2H^{+} + SO_{3}^{2-}}$$
- 不稳定性
- 还原性较突出（$\mathrm{H_{2}SO_{3} + O_{2} \rightarrow H_{2}SO_{4}}$）
- 在较强还原剂作用下表现出氧化性：$\mathrm{H_{2}SO_{3} + 2H_{2}S \rightarrow 3S\downarrow + 3H_{2}O}$

**亚硫酸盐**：
- 绝大多数正盐（$\mathrm{K^{+}}$、$\mathrm{Na^{+}}$、$\mathrm{NH_{4}^{+}}$ 除外）不溶于水，酸式盐多溶于水
- 热稳定性差：$\mathrm{4Na_{2}SO_{3} \rightarrow 3Na_{2}SO_{4} + Na_{2}S}$（加热）
- $\mathrm{SO_{3}^{2-} + 2H^{+} -> SO_{2}↑ + H_{2}O}$（鉴定 $\mathrm{SO_{3}^{2-}}$）
- 除氯剂：$\mathrm{SO_{3}^{2-} + Cl_{2} + H_{2}O -> SO_{4}^{2-} + 2Cl^{-} + 2H^{+}}$
- 保险粉 $\mathrm{Na_{2}S_{2}O_{4}}$：强还原剂

#### 2. 三氧化硫、硫酸及其盐

**三氧化硫**：
- 强氧化剂：$\mathrm{5SO_{3} + 2P \rightarrow 5SO_{2} + P_{2}O_{5}}$
- 强吸水性：$\mathrm{SO_{3} + H_{2}O \rightarrow H_{2}SO_{4}}$

**硫酸**：
- S 采用 $sp^3$ 杂化，分子中除 $\sigma$ 键外，还存在 $(p-d)$ $\pi$ 反馈配键
- 性质：酸性、吸水性、氧化性

**硫酸盐**：
- 正盐难溶：$\mathrm{BaSO_{4}}$、$\mathrm{PbSO_{4}}$、$\mathrm{CaSO_{4}}$；酸式盐大都溶于水
- $\mathrm{SO_{4}^{2-}}$ 鉴定：$\mathrm{Ba^{2+} + SO_{4}^{2-} -> BaSO_{4}↓}$（白色，在 HCl 存在时）

**矾**——带结晶水的过渡金属硫酸盐：
- $\mathrm{CuSO_{4}·5H_{2}O}$ 蓝矾
- $\mathrm{FeSO_{4}·7H_{2}O}$ 绿矾
- 通式：$\mathrm{M^I_{2}SO_{4}·M^{II}SO_{4}·6H_{2}O}$（如摩尔盐 $(NH_{4})_{2}SO_{4}·FeSO_{4}·6H_{2}O$）
- 明矾：$\mathrm{K_{2}SO_{4}·Al_{2}(SO_{4})_{3}·24H_{2}O}$

#### 3. 焦硫酸及其盐
- $\mathrm{H_{2}S_{2}O_{7}}$：比硫酸具有更强的氧化性、吸水性和腐蚀性
- 焦硫酸盐受热分解：$\mathrm{K_{2}S_{2}O_{7} \rightarrow K_{2}SO_{4} + SO_{3}\uparrow }$
- 分析化学中用作熔矿剂

#### 4. 硫代硫酸及其盐
- **硫代硫酸钠**（海波、大苏打）：$\mathrm{Na_{2}S_{2}O_{3}}$
- 制备：$\mathrm{Na_{2}SO_{3} + S \rightarrow Na_{2}S_{2}O_{3}}$（煮沸）
- **遇酸分解**：$\mathrm{S_{2}O_{3}^{2-} + 2H^{+} -> S↓ + SO_{2}↑ + H_{2}O}$（鉴定反应）
- **还原性**（为主）：
  - 与强氧化剂：$\mathrm{S_{2}O_{3}^{2-} + 4Cl_{2} + 5H_{2}O -> 2SO_{4}^{2-} + 8Cl^{-} + 10H^{+}}$（除氯剂）
  - 与较弱氧化剂：$\mathrm{2S_{2}O_{3}^{2-} + I_{2} -> S_{4}O_{6}^{2-} + 2I^{-}}$
- **配位能力**：$\mathrm{AgX + 2S_{2}O_{3}^{2-} -> [Ag(S_{2}O_{3})_{2}]^{3-} + X^{-}}$
- 重金属硫代硫酸盐不稳定（白色 $\mathrm{Ag_{2}S_{2}O_{3}}$ 迅速分解为黑色 $\mathrm{Ag_{2}S}$）

#### 5. 过硫酸及其盐
- 过二硫酸盐：$\mathrm{Na_{2}S_{2}O_{8}}$ 和 $(NH_{4})_{2}S_{2}O_{8}$
- **强氧化性**：$\mathrm{S_{2}O_{8}^{2-} + 2e^{-} -> 2SO_{4}^{2-}}$，$\varphi^\theta = 2.0\ \text{V}$
- $\mathrm{Mn^{2+} + 5S_{2}O_{8}^{2-} + 8H_{2}O -> 2MnO_{4}^{-} + 10SO_{4}^{2-} + 16H^{+}}$

## 知识要点

1. 氧族元素价层电子构型 $ns^2np^4$，从上到下金属性增强，非金属性减弱
2. 氧气分子键级为 2，有顺磁性；臭氧有反磁性，是强氧化剂
3. 过氧化氢兼具氧化性和还原性，是二元弱酸，不稳定易分解
4. 氧化物酸碱性规律：同周期从左到右碱性→两性→酸性；同族从上到下碱性增强
5. 硫有斜方硫、单斜硫、弹性硫三种同素异形体
6. 硫化氢有较强还原性，可作沉淀剂
7. 亚硫酸以还原性为主，硫酸是强酸、强氧化剂
8. 硫代硫酸钠（海波）：遇酸分解，还原性 $\mathrm{I_{2}}$ 生成连四硫酸盐，能与 $\mathrm{Ag^{+}}$ 配位
9. 过硫酸盐是强氧化剂（$\varphi^\theta = 2.0\ \text{V}$）
10. 焦硫酸盐用作熔矿剂，矾是带结晶水的过渡金属硫酸盐
