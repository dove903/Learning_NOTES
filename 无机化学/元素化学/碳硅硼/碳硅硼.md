## 17.1 通性

碳、硅属于同一族（IVA），有相似性；硼和硅在周期表中处于**对角线位置**，也有相似性。

- **碳**：有机世界的主角，自相结合成链的能力最强，化合物最多
- **硅**：无机世界的主角，二氧化硅是地壳的主要成分
- **硼**：近期研究活跃，可与碳媲美

### 一、元素的基本性质

| 性质 | 碳（C） | 硅（Si） | 硼（B） |
|------|---------|----------|---------|
| 原子序数 | 6 | 14 | 5 |
| 价电子层结构 | $2s^22p^2$ | $3s^23p^2$ | $2s^22p^1$ |
| 主要氧化态 | +IV, +II, 0 (-II, -IV) | +IV (+II), 0, (-IV) | +III, 0 |
| 共价半径 / pm | 77 | 117 | 88 |
| 第一电离能 / kJ·mol⁻¹ | 1086.5 | 786.6 | 800.7 |
| 电子亲和能 / kJ·mol⁻¹ | 121.9 | 133.6 | 26.73 |
| 电负性 | 2.5 | 1.8 | 2.0 |

### 二、电子构型和成键性质

- **足电子原子**：价电子数 = 价层轨道数（C、Si）
  - C：价电子数(4) = 价层轨道数(4)
  - Si：价电子数(4) = 价层轨道数(4)
- **缺电子原子**：价电子数 < 价层轨道数（B）
  - B：价电子数(3) < 价层轨道数(4)

### 三、成键特点

| 性质 | 碳 C | 硅 Si | 硼 B |
|------|------|-------|------|
| 类型 | 足电子原子 | 足电子原子 | 缺电子原子 |
| 键型 | 共价键 | 共价键 | 共价键 |
| 常见杂化类型 | $sp^n$ | $sp^3$, $sp^3d^2$ | $sp^3$, $sp^2$ |
| 常见配位数 | 4, 3, 2 | 4 | 4, 3 |
| 成键特点 | $\sigma$ 键，$p$-$p$ $\pi$ 键（大 $\pi$ 键，多重键） | $\sigma$ 键，$d$-$p$ $\pi$ 键 | $\sigma$ 键，多中心键（3c-2e） |

共性：自相结合成链，有一系列氢化物；C 和 Si 是**亲氧元素**，自然界以含氧化合物形式存在。

### 四、自然存在和丰度

| 元素 | 地壳丰度 | 同位素 | 存在形式 |
|------|---------|--------|---------|
| 碳 | 0.023% | $^{12}\mathrm{C}$ 98.93%, $^{13}\mathrm{C}$ 1.07%, $^{14}\mathrm{C}$ 放射性 | 金刚石、石墨、$\mathrm{C_{60}}$、$\mathrm{CO_{2}}$、碳酸盐 |
| 硅 | 25.9% | — | 石英矿 ($\mathrm{SiO_{2}}$)、硅酸盐 |
| 硼 | $1.2 × 10^{-3}$% | — | 硼酸盐 |

## 17.2 碳

### 一、碳族元素的单质

#### 1. 碳的同素异形体

| 性质 | 金刚石 | 石墨 | $\mathrm{C_{60}}$（富勒烯） |
|------|--------|------|---------------------|
| 杂化形式 | $sp^3$ 等性 | $sp^2$ | $sp^{2.28}$ |
| 键角 | 109.5° | 120° | 116° |
| 密度 / g·cm⁻³ | 3.514 | 2.266 | 1.678 |
| $\mathrm{C-C}$ 键长 / pm | 154.4 | 141.8 | (6/6)139.1; (6/5)145.5 |
| 导电性 | 不导电 | 导电 | — |

- **金刚石**：硬度最大、熔点最高的单质（mp 3823 K），$sp^3$ 等性杂化，无自由电子
- **石墨**：硬度小，熔点极高，层状结构，$sp^2$ 杂化，层内形成 $\pi$ 键（离域 $\pi$ 电子导电），层间分子间作用力小（润滑性）
- **$\mathrm{C_{60}}$**（足球烯）：截角正二十面体，20 个正六边形 + 12 个正五边形
- 还有管碳、白碳、石墨炔等其他同素异形体

### 二、碳的氧化物、含氧酸及其盐

#### 1. 一氧化碳（CO）

**分子结构**：
- CO 与 $\mathrm{N_{2}}$、$\mathrm{CN^{-}}$、$\mathrm{NO^{+}}$ 是等电子体，结构相似
- 分子中有三重键：一个 $\sigma$ 键，两个 $\pi$ 键
- 不同点：CO 的一个 $\pi$ 键是从 C 到 O 的 $\pi$ 配键，偶极矩很小，比 $\mathrm{N_{2}}$ 活泼

**化学性质**：
- **还原性**：$\mathrm{CO + PdCl_{2} + H_{2}O \rightarrow Pd\downarrow + CO_{2} + 2HCl}$（鉴定 CO）
- **配位性**：$\mathrm{CO}$ 中 C 提供孤对电子，如 $[\mathrm{Cu(NH_{3})_{3}CO}]^+$（铜洗液吸收 CO）
- **与碱作用**（弱酸性）：$\mathrm{CO + NaOH \rightarrow HCOONa}$
- **与其他非金属作用**：$\mathrm{CO + Cl_{2} \rightarrow COCl_{2}}$（光气）

#### 2. 二氧化碳（$\mathrm{CO_{2}}$）

**结构**：C 为 $sp$ 等性杂化，2 个 $\sigma$ 键，两个 $\pi_3^4$ 键。

**性质**：
- 非极性分子，易液化，临界温度 304 K
- 固体为"干冰"，分子晶体（特定条件下可形成原子晶体）
- **化学性质不活泼**，高温下能与碳或活泼金属（Mg、Na）反应
- **酸性**：能与碱、碱性氧化物及碳酸盐反应
- 鉴定：$\mathrm{CO_{2} + Ca(OH)_{2} \rightarrow CaCO_{3}\downarrow + H_{2}O}$
- 用途：致冷剂、舞台烟云

#### 3. 碳酸和碳酸盐

**$\mathrm{H_{2}CO_{3}}$**：C 采用 $sp^2$ 等性杂化，与端 O 形成 $\sigma$ 键 + $\pi$ 键，与羟基 O 形成 2 个 $\sigma$ 键。

**$\mathrm{CO_{3}^{2-}}$**：C 采用 $sp^2$ 等性杂化，存在 $\pi_4^6$ 离域 $\pi$ 键。

**碳酸盐分类**：
- 正盐：$\mathrm{M^I_{2}CO_{3}}$、$\mathrm{M^{II}CO_{3}}$
- 酸式碳酸盐：$\mathrm{M^IHCO_{3}}$
- 碱式碳酸盐：$\mathrm{M_{2}^{II}(OH)_{2}CO_{3}}$

**溶解性**：
- 碳酸盐：铵和碱金属（Li 除外）易溶，其他难溶
- 对于难溶碳酸盐，酸式盐溶解度 > 正盐
- 对于易溶碳酸盐，酸式盐溶解度反而较小（$\mathrm{HCO_{3}^{-}}$ 间氢键缔合）

**水解性**：
- $\mathrm{Na_{2}CO_{3}}$ 溶液中两种沉淀剂：$\mathrm{OH^{-}}$ 和 $\mathrm{CO_{3}^{2-}}$
- 金属离子加入可溶性碳酸盐时的沉淀类型：
  1. 氢氧化物碱性较强的离子 → 碳酸盐沉淀（如 $\mathrm{Ba^{2+}}$、$\mathrm{Ca^{2+}}$）
  2. 氢氧化物碱性较弱 → 碱式碳酸盐沉淀（如 $\mathrm{Cu^{2+}}$、$\mathrm{Zn^{2+}}$）
  3. 强水解性金属离子 → 氢氧化物沉淀（如 $\mathrm{Al^{3+}}$、$\mathrm{Fe^{3+}}$）

**热稳定性**：
$$\mathrm{H_{2}CO_{3} < MHCO_{3} < M_{2}CO_{3}}$$
$$\text{碱金属盐 > 碱土金属盐 > 过渡金属盐 > 铵盐 > 酸}$$

| 碳酸盐 | 分解温度 / ℃ |
|--------|-------------|
| $\mathrm{BeCO_{3}}$ | 100 |
| $\mathrm{MgCO_{3}}$ | 540 |
| $\mathrm{CaCO_{3}}$ | 900 |
| $\mathrm{SrCO_{3}}$ | 1290 |
| $\mathrm{BaCO_{3}}$ | 1360 |
| $\mathrm{PbCO_{3}}$ | 315 |
| $\mathrm{ZnCO_{3}}$ | 350 |
| $\mathrm{FeCO_{3}}$ | 282 |

- 金属离子的极化力越强，碳酸盐热稳定性越差
- 同一族碱土金属碳酸盐稳定性从上到下增加
- 过渡金属碳酸盐稳定性差

## 17.3 硅

### 一、单质硅

- **结构**：金刚石型
- **物理性质**：质地坚硬有脆性，熔沸点极高，颜色灰黑有金属光泽
- **化学性质**：常温不活泼；高温下与 $\mathrm{O_{2}}$、$\mathrm{Cl_{2}}$、$\mathrm{N_{2}}$ 反应（还原性），与 Ca、Mg、Mn 反应（氧化性）
- 与碱作用：$\mathrm{Si + 2NaOH + H_{2}O \rightarrow Na_{2}SiO_{3} + 2H_{2}\uparrow }$
- 与 HF 反应（有氧化剂存在）：$\mathrm{3Si + 4HNO_{3} + 18HF \rightarrow 3H_{2}SiF_{6} + 4NO + 8H_{2}O}$

**制备**：
- 粗硅：$\mathrm{SiO_{2} + 2C \rightarrow Si(粗) + 2CO}$（电炉，1800℃）
- 提纯：$\mathrm{Si + 2Cl_{2} \rightarrow SiCl_{4}}$ → 蒸馏 → $\mathrm{SiCl_{4} + 2H_{2} \rightarrow Si(纯) + 4HCl}$

### 二、硅烷

硅与碳相似，有自相结合成链的能力，但硅烷种类比烷烃少得多（$\mathrm{Si_nH_{2n+2}}$，$n \le 6$）。

**原因**：$\mathrm{Si-Si}$ 键不如 $\mathrm{C-C}$ 键强，特别是 $\mathrm{Si=Si}$ 双键，因为 Si 原子半径大，成 $\sigma$ 键时原子轨道重叠程度小，成 $\pi$ 键时更小。

**$\mathrm{SiH_{4}}$（甲硅烷）**：
- 无色无臭气体，随链增加热稳定性下降，室温下只有 $\mathrm{SiH_{4}}$ 稳定

**$\mathrm{SiH_{4}}$ 与 $\mathrm{CH_{4}}$ 的比较**：
| 性质 | $\mathrm{SiH_{4}}$ | $\mathrm{CH_{4}}$ |
|------|------------|------------|
| 稳定性 | 差（773 K 分解） | 好（1773 K 分解） |
| 还原性 | 强，能自燃 | 不能自燃 |
| 水解性 | 易水解：$\mathrm{SiH_{4} + 4H_{2}O \rightarrow SiO_{2}·nH_{2}O + 4H_{2}\uparrow }$ | 不水解 |

### 三、硅的卤化物和氟硅酸盐

#### 1. 卤化物 $\mathrm{SiX_{4}}$

| 性质 | $\mathrm{SiF_{4}}$ | $\mathrm{SiCl_{4}}$ | $\mathrm{SiBr_{4}}$ | $\mathrm{SiI_{4}}$ |
|------|------------|--------------|--------------|--------------|
| 聚集态 | 气 | 液 | 液 | 固 |
| 熔沸点 | 低 → 高 | | | |

- 键能：$\mathrm{SiX_{4} > CX_{4}}$；键长：$\mathrm{SiX_{4} > CX_{4}}$
- $\mathrm{SiX_{4}}$ 与 $\mathrm{CX_{4}}$ 不同：$\mathrm{SiX_{4}}$ 极易水解
  - $\mathrm{SiCl_{4} + 4H_{2}O \rightarrow H_{4}SiO_{4} + 4HCl}$（空气中潮解发烟）
  - $\mathrm{SiF_{4} + 4H_{2}O \rightarrow H_{4}SiO_{4} + 4HF}$；$\mathrm{SiF_{4} + 2HF \rightarrow H_{2}SiF_{6}}$（酸性比硫酸还强）

#### 2. 氟硅酸盐
- $\mathrm{H_{2}SiF_{6}}$ 是强酸（与 $\mathrm{H_{2}SO_{4}}$ 相近），但纯品尚未制得
- $\mathrm{Na_{2}SiF_{6}}$、$\mathrm{K_{2}SiF_{6}}$ 较难溶，$\mathrm{PbSiF_{6}}$ 易溶
- $\mathrm{Na_{2}SiF_{6}}$：杀虫剂、搪瓷乳白剂、木材防腐剂

### 四、硅的含氧化合物

#### 1. 二氧化硅（$\mathrm{SiO_{2}}$）

**结构**：
- 晶体：原子晶体，基本结构单元是**硅氧四面体** $\mathrm{SiO_{4}}$，最简式 $\mathrm{SiO_{2}}$
- 无定形：硅氧四面体杂乱排列

**形态**：
- 晶体：石英（纯→水晶；含杂质→玛瑙、紫晶、碧玉；细粒→砂粒）
- 无定形：石英玻璃、硅藻土、燧石

**化学性质**：
- 酸性氧化物（硅酸的酸酐）
- 与热的浓碱反应
- 与氟作用
- 高温下被 Mg、Al、B 还原
- 在无机酸中只与 $\mathrm{HF}$ 作用
- 用途：石英玻璃制耐高温仪器、光导纤维

#### 2. 硅酸

$$\mathrm{SiO_{4}^{4-} + 4H^{+} -> H_{4}SiO_{4}}\quad (\text{正硅酸})\ K_a = 3.0 × 10^{-10}$$

硅酸根之间易缩合，组成复杂：
| 名称 | 化学式 |
|------|--------|
| 偏硅酸 | $\mathrm{H_{2}SiO_{3}}$ ($x=1, y=1$) |
| 正硅酸 | $\mathrm{H_{4}SiO_{4}}$ ($x=1, y=2$) |
| 二偏硅酸 | $\mathrm{H_{2}Si_{2}O_{5}}$ ($x=2, y=1$) |
| 焦硅酸 | $\mathrm{H_{6}Si_{2}O_{7}}$ ($x=2, y=3$) |

**硅胶**：$\mathrm{Na_{2}SiO_{3} + 2H^{+} \rightarrow H_{2}SiO_{3} + 2Na^{+}}$，至 pH = 7~8 时缩聚成凝胶，多孔硅胶可做干燥剂。

#### 3. 硅酸盐

**可溶性**：$\mathrm{Na_{2}SiO_{3}}$（水玻璃）、$\mathrm{K_{2}SiO_{3}}$
**不溶性**：大部分难溶于水，有特征颜色

**天然硅酸盐**：
- 基本结构单元：**硅氧四面体** $\mathrm{SiO_{4}}$
- 通式：$a\mathrm{M}_x\mathrm{O}_y·b\mathrm{SiO_{2}}·c\mathrm{H_{2}O}$
- 结构类型：
  - **链状**：硅氧四面体共用两个顶点（如石棉）
  - **片状**：硅氧四面体共用三个顶点（如云母）
  - **三维网络状**：共用四个顶点（如沸石分子筛，有吸附性和筛分能力）

## 17.4 硼

### 一、硼原子的成键特征

价电子构型 $2s^22p^1$，成键时激发为 $2s^12p_x^12p_y^12p_z^1$。

**三个成键特征**：
1. **共价性**（原子半径小，电离能高，电负性大）
2. **易形成配合物和缺电子多中心键**
   - 配合物：$\mathrm{HF + BF_{3} \rightarrow HBF_{4}}$
   - 桥式 $\mathrm{B-H-B}$ 键（3c-2e）
   - 开式 $\mathrm{B-B-B}$ 硼桥键（3c-2e）
   - 闭式 $\mathrm{B-B-B}$ 硼桥键（3c-2e）
3. **硼单质和硼烷的基本结构是以三面体组成的多面体**

### 二、单质硼

- 无定形硼和晶体硼
- 晶体硼以 $\mathrm{B_{12}}$ 二十面体为基本单元
- 晶态硼：原子晶体，硬度大，熔沸点高，化学性质不活泼
- 无定形硼：较活泼

**化学性质**：
$$\mathrm{4B + 3O_{2} \rightarrow 2B_{2}O_{3}}$$
$$\mathrm{2B + 3Cl_{2} \rightarrow 2BCl_{3}}$$
$$\mathrm{2B + N_{2} \rightarrow 2BN}$$
$$\mathrm{2B + 6H_{2}O \rightarrow 2H_{3}BO_{3} + 3H_{2}\uparrow }$$
$$\mathrm{B + 3HNO_{3}(浓) \rightarrow H_{3}BO_{3} + 3NO_{2}}$$
$$\mathrm{2B + 2NaOH(浓) + H_{2}O \rightarrow 2NaBO_{2} + 3H_{2}\uparrow }$$

### 三、硼的氢化物（硼烷）和硼氢配合物

- 硼烷种类比硅烷多，结构更复杂
- 无色、抗磁性、多数有毒、不稳定
- 物理化学性质更像硅烷

**乙硼烷（$\mathrm{B_{2}H_{6}}$）**：
- 最简单的硼烷
- 强还原性（自燃，高能燃料，剧毒）：$\mathrm{B_{2}H_{6} + 3O_{2} \rightarrow B_{2}O_{3} + H_{2}O}$，$\Delta_r H_m^\theta = -2034\ \text{kJ/mol}$
- 水解性：$\mathrm{B_{2}H_{6} + 6H_{2}O \rightarrow 2B(OH)_{3}\downarrow + 6H_{2}}$
- 加合反应：$\mathrm{3B_{2}H_{6} + 6NH_{3} \rightarrow 2B_{3}N_{3}H_{6}}$（环氮硼烷）+ $\mathrm{12H_{2}}$
- $\mathrm{B_{2}H_{6} + 2LiH \rightarrow 2LiBH_{4}}$（白色固体，火箭推进剂）

**环氮硼烷（$\mathrm{B_{3}N_{3}H_{6}}$）**：与苯是等电子体，俗称"**无机苯**"。

### 四、硼的卤化物和氟硼酸

- 同种卤素的三卤化物（$\mathrm{BX_{3}}$）最为稳定
- 所有 $\mathrm{BX_{3}}$ 都是**平面三角形**分子，分子内有离域 $\pi$ 键

**水解性**：
$$\mathrm{BCl_{3} + 3H_{2}O \rightarrow H_{3}BO_{3} + 3HCl}$$
$$\mathrm{4BF_{3} + 6H_{2}O \rightarrow H_{3}BO_{3} + 3H_{3}O^{+} + 3BF_{4}^{-}}$$
$\mathrm{HBF_{4}}$ 和 $\mathrm{H_{2}SiF_{6}}$ 一样，是强酸，仅以离子状态存在于水溶液中。

### 五、硼的含氧化合物

#### 1. 三氧化二硼（$\mathrm{B_{2}O_{3}}$）

- 制备：$\mathrm{2H_{3}BO_{3} \rightarrow B_{2}O_{3} + 3H_{2}O}$
- 性质：能被碱金属、Mg、Al 还原为单质硼
- **硼珠试验**：熔融态 $\mathrm{B_{2}O_{3}}$ 能溶解金属氧化物，形成特征颜色

| 金属氧化物 | 硼珠颜色 |
|-----------|---------|
| $\mathrm{CoO}$ | 深蓝色 |
| $\mathrm{Cr_{2}O_{3}}$ | 绿色 |
| $\mathrm{CuO}$ | 蓝色 |
| $\mathrm{MnO}$ | 紫色 |
| $\mathrm{NiO}$ | 绿色 |
| $\mathrm{Fe_{2}O_{3}}$ | 黄色 |

#### 2. 硼酸

- **一元弱酸**：$\mathrm{B(OH)_{3} + H_{2}O \rightarrow B(OH)_{4}^{-} + H^{+}}$，$K_a = 7.3 × 10^{-10}$
- 结构：B 为 $sp^2$ 杂化
- 加入甘油（丙三醇）可增强酸性
- 鉴定：$\mathrm{H_{3}BO_{3} + 3CH_{3}OH \rightarrow B(OCH_{3})_{3} + 3H_{2}O}$，硼酸酯燃烧有**绿色火焰**
- 脱水序列：$\mathrm{4H_{3}BO_{3} \rightarrow 4HBO_{2} \rightarrow H_{2}B_{4}O_{7} \rightarrow 2B_{2}O_{3}}$

#### 3. 硼酸盐

- 基本结构单元：$\mathrm{BO_{3}}$ 平面三角形和 $\mathrm{BO_{4}}$ 四面体
- **硼砂**（四硼酸钠）：$\mathrm{Na_{2}B_{4}O_{5}(OH)_{4}·8H_{2}O}$（习惯写作 $\mathrm{Na_{2}B_{4}O_{7}·10H_{2}O}$）
- 结构：四个硼原子中，两个 $\mathrm{BO_{3}}$ 平面三角形和两个 $\mathrm{BO_{4}}$ 四面体
- 易水解显碱性，水溶液具有缓冲作用
- 硼砂熔融态能溶解金属氧化物（与硼珠试验类似）

#### 4. 氮化硼（BN）

- 制备：$\mathrm{Na_{2}B_{4}O_{7} + 2NH_{4}Cl \rightarrow 2NaCl + B_{2}O_{3} + 2BN + 4H_{2}O}$
- 结构：具有石墨型晶体结构，但不导电
- 化学式：$(\mathrm{BN})_x$

## 知识要点

1. 碳、硅同属 IVA 族，硼与硅处于对角线位置，有相似性
2. 碳是足电子原子，硼是缺电子原子（形成 3c-2e 多中心键）
3. 碳的同素异形体：金刚石（$sp^3$，不导电）、石墨（$sp^2$，导电，润滑）、$\mathrm{C_{60}}$（$sp^{2.28}$）
4. CO 与 $\mathrm{N_{2}}$ 等电子体，有还原性和配位性；$\mathrm{CO_{2}}$ 为 $sp$ 杂化，酸性氧化物
5. 碳酸盐热稳定性：$\mathrm{H_{2}CO_{3} < MHCO_{3} < M_{2}CO_{3}}$，金属离子极化力越强越不稳定
6. 硅烷比烷烃少且不稳定，$\mathrm{SiH_{4}}$ 能自燃，易水解
7. $\mathrm{SiCl_{4}}$ 极易水解；$\mathrm{H_{2}SiF_{6}}$ 是强酸
8. 硅氧四面体是硅酸盐的基本结构单元（链状、片状、三维网络状）
9. 硼的三个成键特征：共价性、缺电子多中心键、以 $\mathrm{B_{12}}$ 二十面体为基础
10. 硼酸是一元弱酸（$K_a = 7.3 × 10^{-10}$），鉴定反应生成硼酸酯有绿色火焰
11. 硼砂易水解显碱性，有缓冲作用；硼珠试验用于鉴别金属离子
