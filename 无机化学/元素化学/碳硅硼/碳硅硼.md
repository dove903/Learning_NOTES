# 第17章 碳 硅 硼

> 主讲：王申堂 | 化学化工学院 | 第四篇 元素化学（一）非金属

## 17.1 通性

碳、硅属于同一族（IVA），有相似性；硼和硅在周期表中处于**对角线位置**，也有相似性。

- **碳**：有机世界的主角，自相结合成链的能力最强，化合物最多
- **硅**：无机世界的主角，二氧化硅是地壳的主要成分
- **硼**：近期研究活跃，可与碳媲美

### 一、元素的基本性质

| 性质 | 碳（C） | 硅（Si） | 硼（B） |
|------|---------|----------|---------|
| 原子序数 | 6 | 14 | 5 |
| 价电子层结构 | $2s^22p^2$ | $3s^23p^2$ | $2s^22p^1$ |
| 主要氧化态 | +IV, +II, 0 (-II, -IV) | +IV (+II), 0, (-IV) | +III, 0 |
| 共价半径 / pm | 77 | 117 | 88 |
| 第一电离能 / kJ·mol⁻¹ | 1086.5 | 786.6 | 800.7 |
| 电子亲和能 / kJ·mol⁻¹ | 121.9 | 133.6 | 26.73 |
| 电负性 | 2.5 | 1.8 | 2.0 |

### 二、电子构型和成键性质

- **足电子原子**：价电子数 = 价层轨道数（C、Si）
  - C：价电子数(4) = 价层轨道数(4)
  - Si：价电子数(4) = 价层轨道数(4)
- **缺电子原子**：价电子数 < 价层轨道数（B）
  - B：价电子数(3) < 价层轨道数(4)

### 三、成键特点

| 性质 | 碳 C | 硅 Si | 硼 B |
|------|------|-------|------|
| 类型 | 足电子原子 | 足电子原子 | 缺电子原子 |
| 键型 | 共价键 | 共价键 | 共价键 |
| 常见杂化类型 | $sp^n$ | $sp^3$, $sp^3d^2$ | $sp^3$, $sp^2$ |
| 常见配位数 | 4, 3, 2 | 4 | 4, 3 |
| 成键特点 | $\sigma$ 键，$p$-$p$ $\pi$ 键（大 $\pi$ 键，多重键） | $\sigma$ 键，$d$-$p$ $\pi$ 键 | $\sigma$ 键，多中心键（3c-2e） |

共性：自相结合成链，有一系列氢化物；C 和 Si 是**亲氧元素**，自然界以含氧化合物形式存在。

### 四、自然存在和丰度

| 元素 | 地壳丰度 | 同位素 | 存在形式 |
|------|---------|--------|---------|
| 碳 | 0.023% | $^{12}\ce{C}$ 98.93%, $^{13}\ce{C}$ 1.07%, $^{14}\ce{C}$ 放射性 | 金刚石、石墨、$\ce{C60}$、$\ce{CO2}$、碳酸盐 |
| 硅 | 25.9% | — | 石英矿 ($\ce{SiO2}$)、硅酸盐 |
| 硼 | $1.2 × 10^{-3}$% | — | 硼酸盐 |

## 17.2 碳

### 一、碳族元素的单质

#### 1. 碳的同素异形体

| 性质 | 金刚石 | 石墨 | $\ce{C60}$（富勒烯） |
|------|--------|------|---------------------|
| 杂化形式 | $sp^3$ 等性 | $sp^2$ | $sp^{2.28}$ |
| 键角 | 109.5° | 120° | 116° |
| 密度 / g·cm⁻³ | 3.514 | 2.266 | 1.678 |
| $\ce{C-C}$ 键长 / pm | 154.4 | 141.8 | (6/6)139.1; (6/5)145.5 |
| 导电性 | 不导电 | 导电 | — |

- **金刚石**：硬度最大、熔点最高的单质（mp 3823 K），$sp^3$ 等性杂化，无自由电子
- **石墨**：硬度小，熔点极高，层状结构，$sp^2$ 杂化，层内形成 $\pi$ 键（离域 $\pi$ 电子导电），层间分子间作用力小（润滑性）
- **$\ce{C60}$**（足球烯）：截角正二十面体，20 个正六边形 + 12 个正五边形
- 还有管碳、白碳、石墨炔等其他同素异形体

### 二、碳的氧化物、含氧酸及其盐

#### 1. 一氧化碳（CO）

**分子结构**：
- CO 与 $\ce{N2}$、$\ce{CN-}$、$\ce{NO+}$ 是等电子体，结构相似
- 分子中有三重键：一个 $\sigma$ 键，两个 $\pi$ 键
- 不同点：CO 的一个 $\pi$ 键是从 C 到 O 的 $\pi$ 配键，偶极矩很小，比 $\ce{N2}$ 活泼

**化学性质**：
- **还原性**：$\ce{CO + PdCl2 + H2O -> Pd↓ + CO2 + 2HCl}$（鉴定 CO）
- **配位性**：$\ce{CO}$ 中 C 提供孤对电子，如 $[\ce{Cu(NH3)3CO}]^+$（铜洗液吸收 CO）
- **与碱作用**（弱酸性）：$\ce{CO + NaOH -> HCOONa}$
- **与其他非金属作用**：$\ce{CO + Cl2 -> COCl2}$（光气）

#### 2. 二氧化碳（$\ce{CO2}$）

**结构**：C 为 $sp$ 等性杂化，2 个 $\sigma$ 键，两个 $\pi_3^4$ 键。

**性质**：
- 非极性分子，易液化，临界温度 304 K
- 固体为"干冰"，分子晶体（特定条件下可形成原子晶体）
- **化学性质不活泼**，高温下能与碳或活泼金属（Mg、Na）反应
- **酸性**：能与碱、碱性氧化物及碳酸盐反应
- 鉴定：$\ce{CO2 + Ca(OH)2 -> CaCO3↓ + H2O}$
- 用途：致冷剂、舞台烟云

#### 3. 碳酸和碳酸盐

**$\ce{H2CO3}$**：C 采用 $sp^2$ 等性杂化，与端 O 形成 $\sigma$ 键 + $\pi$ 键，与羟基 O 形成 2 个 $\sigma$ 键。

**$\ce{CO3^{2-}}$**：C 采用 $sp^2$ 等性杂化，存在 $\pi_4^6$ 离域 $\pi$ 键。

**碳酸盐分类**：
- 正盐：$\ce{M^I2CO3}$、$\ce{M^{II}CO3}$
- 酸式碳酸盐：$\ce{M^IHCO3}$
- 碱式碳酸盐：$\ce{M2^{II}(OH)2CO3}$

**溶解性**：
- 碳酸盐：铵和碱金属（Li 除外）易溶，其他难溶
- 对于难溶碳酸盐，酸式盐溶解度 > 正盐
- 对于易溶碳酸盐，酸式盐溶解度反而较小（$\ce{HCO3-}$ 间氢键缔合）

**水解性**：
- $\ce{Na2CO3}$ 溶液中两种沉淀剂：$\ce{OH-}$ 和 $\ce{CO3^{2-}}$
- 金属离子加入可溶性碳酸盐时的沉淀类型：
  1. 氢氧化物碱性较强的离子 → 碳酸盐沉淀（如 $\ce{Ba^{2+}}$、$\ce{Ca^{2+}}$）
  2. 氢氧化物碱性较弱 → 碱式碳酸盐沉淀（如 $\ce{Cu^{2+}}$、$\ce{Zn^{2+}}$）
  3. 强水解性金属离子 → 氢氧化物沉淀（如 $\ce{Al^{3+}}$、$\ce{Fe^{3+}}$）

**热稳定性**：
$$\ce{H2CO3 < MHCO3 < M2CO3}$$
$$\text{碱金属盐 > 碱土金属盐 > 过渡金属盐 > 铵盐 > 酸}$$

| 碳酸盐 | 分解温度 / ℃ |
|--------|-------------|
| $\ce{BeCO3}$ | 100 |
| $\ce{MgCO3}$ | 540 |
| $\ce{CaCO3}$ | 900 |
| $\ce{SrCO3}$ | 1290 |
| $\ce{BaCO3}$ | 1360 |
| $\ce{PbCO3}$ | 315 |
| $\ce{ZnCO3}$ | 350 |
| $\ce{FeCO3}$ | 282 |

- 金属离子的极化力越强，碳酸盐热稳定性越差
- 同一族碱土金属碳酸盐稳定性从上到下增加
- 过渡金属碳酸盐稳定性差

## 17.3 硅

### 一、单质硅

- **结构**：金刚石型
- **物理性质**：质地坚硬有脆性，熔沸点极高，颜色灰黑有金属光泽
- **化学性质**：常温不活泼；高温下与 $\ce{O2}$、$\ce{Cl2}$、$\ce{N2}$ 反应（还原性），与 Ca、Mg、Mn 反应（氧化性）
- 与碱作用：$\ce{Si + 2NaOH + H2O -> Na2SiO3 + 2H2↑}$
- 与 HF 反应（有氧化剂存在）：$\ce{3Si + 4HNO3 + 18HF -> 3H2SiF6 + 4NO + 8H2O}$

**制备**：
- 粗硅：$\ce{SiO2 + 2C -> Si(粗) + 2CO}$（电炉，1800℃）
- 提纯：$\ce{Si + 2Cl2 -> SiCl4}$ → 蒸馏 → $\ce{SiCl4 + 2H2 -> Si(纯) + 4HCl}$

### 二、硅烷

硅与碳相似，有自相结合成链的能力，但硅烷种类比烷烃少得多（$\ce{Si_nH_{2n+2}}$，$n \le 6$）。

**原因**：$\ce{Si-Si}$ 键不如 $\ce{C-C}$ 键强，特别是 $\ce{Si=Si}$ 双键，因为 Si 原子半径大，成 $\sigma$ 键时原子轨道重叠程度小，成 $\pi$ 键时更小。

**$\ce{SiH4}$（甲硅烷）**：
- 无色无臭气体，随链增加热稳定性下降，室温下只有 $\ce{SiH4}$ 稳定

**$\ce{SiH4}$ 与 $\ce{CH4}$ 的比较**：
| 性质 | $\ce{SiH4}$ | $\ce{CH4}$ |
|------|------------|------------|
| 稳定性 | 差（773 K 分解） | 好（1773 K 分解） |
| 还原性 | 强，能自燃 | 不能自燃 |
| 水解性 | 易水解：$\ce{SiH4 + 4H2O -> SiO2·nH2O + 4H2↑}$ | 不水解 |

### 三、硅的卤化物和氟硅酸盐

#### 1. 卤化物 $\ce{SiX4}$

| 性质 | $\ce{SiF4}$ | $\ce{SiCl4}$ | $\ce{SiBr4}$ | $\ce{SiI4}$ |
|------|------------|--------------|--------------|--------------|
| 聚集态 | 气 | 液 | 液 | 固 |
| 熔沸点 | 低 → 高 | | | |

- 键能：$\ce{SiX4 > CX4}$；键长：$\ce{SiX4 > CX4}$
- $\ce{SiX4}$ 与 $\ce{CX4}$ 不同：$\ce{SiX4}$ 极易水解
  - $\ce{SiCl4 + 4H2O -> H4SiO4 + 4HCl}$（空气中潮解发烟）
  - $\ce{SiF4 + 4H2O -> H4SiO4 + 4HF}$；$\ce{SiF4 + 2HF -> H2SiF6}$（酸性比硫酸还强）

#### 2. 氟硅酸盐
- $\ce{H2SiF6}$ 是强酸（与 $\ce{H2SO4}$ 相近），但纯品尚未制得
- $\ce{Na2SiF6}$、$\ce{K2SiF6}$ 较难溶，$\ce{PbSiF6}$ 易溶
- $\ce{Na2SiF6}$：杀虫剂、搪瓷乳白剂、木材防腐剂

### 四、硅的含氧化合物

#### 1. 二氧化硅（$\ce{SiO2}$）

**结构**：
- 晶体：原子晶体，基本结构单元是**硅氧四面体** $\ce{SiO4}$，最简式 $\ce{SiO2}$
- 无定形：硅氧四面体杂乱排列

**形态**：
- 晶体：石英（纯→水晶；含杂质→玛瑙、紫晶、碧玉；细粒→砂粒）
- 无定形：石英玻璃、硅藻土、燧石

**化学性质**：
- 酸性氧化物（硅酸的酸酐）
- 与热的浓碱反应
- 与氟作用
- 高温下被 Mg、Al、B 还原
- 在无机酸中只与 $\ce{HF}$ 作用
- 用途：石英玻璃制耐高温仪器、光导纤维

#### 2. 硅酸

$$\ce{SiO4^{4-} + 4H+ -> H4SiO4}\quad (\text{正硅酸})\ K_a = 3.0 × 10^{-10}$$

硅酸根之间易缩合，组成复杂：
| 名称 | 化学式 |
|------|--------|
| 偏硅酸 | $\ce{H2SiO3}$ ($x=1, y=1$) |
| 正硅酸 | $\ce{H4SiO4}$ ($x=1, y=2$) |
| 二偏硅酸 | $\ce{H2Si2O5}$ ($x=2, y=1$) |
| 焦硅酸 | $\ce{H6Si2O7}$ ($x=2, y=3$) |

**硅胶**：$\ce{Na2SiO3 + 2H+ -> H2SiO3 + 2Na+}$，至 pH = 7~8 时缩聚成凝胶，多孔硅胶可做干燥剂。

#### 3. 硅酸盐

**可溶性**：$\ce{Na2SiO3}$（水玻璃）、$\ce{K2SiO3}$
**不溶性**：大部分难溶于水，有特征颜色

**天然硅酸盐**：
- 基本结构单元：**硅氧四面体** $\ce{SiO4}$
- 通式：$a\ce{M}_x\ce{O}_y·b\ce{SiO2}·c\ce{H2O}$
- 结构类型：
  - **链状**：硅氧四面体共用两个顶点（如石棉）
  - **片状**：硅氧四面体共用三个顶点（如云母）
  - **三维网络状**：共用四个顶点（如沸石分子筛，有吸附性和筛分能力）

## 17.4 硼

### 一、硼原子的成键特征

价电子构型 $2s^22p^1$，成键时激发为 $2s^12p_x^12p_y^12p_z^1$。

**三个成键特征**：
1. **共价性**（原子半径小，电离能高，电负性大）
2. **易形成配合物和缺电子多中心键**
   - 配合物：$\ce{HF + BF3 -> HBF4}$
   - 桥式 $\ce{B-H-B}$ 键（3c-2e）
   - 开式 $\ce{B-B-B}$ 硼桥键（3c-2e）
   - 闭式 $\ce{B-B-B}$ 硼桥键（3c-2e）
3. **硼单质和硼烷的基本结构是以三面体组成的多面体**

### 二、单质硼

- 无定形硼和晶体硼
- 晶体硼以 $\ce{B12}$ 二十面体为基本单元
- 晶态硼：原子晶体，硬度大，熔沸点高，化学性质不活泼
- 无定形硼：较活泼

**化学性质**：
$$\ce{4B + 3O2 -> 2B2O3}$$
$$\ce{2B + 3Cl2 -> 2BCl3}$$
$$\ce{2B + N2 -> 2BN}$$
$$\ce{2B + 6H2O -> 2H3BO3 + 3H2↑}$$
$$\ce{B + 3HNO3(浓) -> H3BO3 + 3NO2}$$
$$\ce{2B + 2NaOH(浓) + H2O -> 2NaBO2 + 3H2↑}$$

### 三、硼的氢化物（硼烷）和硼氢配合物

- 硼烷种类比硅烷多，结构更复杂
- 无色、抗磁性、多数有毒、不稳定
- 物理化学性质更像硅烷

**乙硼烷（$\ce{B2H6}$）**：
- 最简单的硼烷
- 强还原性（自燃，高能燃料，剧毒）：$\ce{B2H6 + 3O2 -> B2O3 + H2O}$，$\Delta_r H_m^\theta = -2034\ \text{kJ/mol}$
- 水解性：$\ce{B2H6 + 6H2O -> 2B(OH)3↓ + 6H2}$
- 加合反应：$\ce{3B2H6 + 6NH3 -> 2B3N3H6}$（环氮硼烷）+ $\ce{12H2}$
- $\ce{B2H6 + 2LiH -> 2LiBH4}$（白色固体，火箭推进剂）

**环氮硼烷（$\ce{B3N3H6}$）**：与苯是等电子体，俗称"**无机苯**"。

### 四、硼的卤化物和氟硼酸

- 同种卤素的三卤化物（$\ce{BX3}$）最为稳定
- 所有 $\ce{BX3}$ 都是**平面三角形**分子，分子内有离域 $\pi$ 键

**水解性**：
$$\ce{BCl3 + 3H2O -> H3BO3 + 3HCl}$$
$$\ce{4BF3 + 6H2O -> H3BO3 + 3H3O+ + 3BF4-}$$
$\ce{HBF4}$ 和 $\ce{H2SiF6}$ 一样，是强酸，仅以离子状态存在于水溶液中。

### 五、硼的含氧化合物

#### 1. 三氧化二硼（$\ce{B2O3}$）

- 制备：$\ce{2H3BO3 -> B2O3 + 3H2O}$
- 性质：能被碱金属、Mg、Al 还原为单质硼
- **硼珠试验**：熔融态 $\ce{B2O3}$ 能溶解金属氧化物，形成特征颜色

| 金属氧化物 | 硼珠颜色 |
|-----------|---------|
| $\ce{CoO}$ | 深蓝色 |
| $\ce{Cr2O3}$ | 绿色 |
| $\ce{CuO}$ | 蓝色 |
| $\ce{MnO}$ | 紫色 |
| $\ce{NiO}$ | 绿色 |
| $\ce{Fe2O3}$ | 黄色 |

#### 2. 硼酸

- **一元弱酸**：$\ce{B(OH)3 + H2O -> B(OH)4- + H+}$，$K_a = 7.3 × 10^{-10}$
- 结构：B 为 $sp^2$ 杂化
- 加入甘油（丙三醇）可增强酸性
- 鉴定：$\ce{H3BO3 + 3CH3OH -> B(OCH3)3 + 3H2O}$，硼酸酯燃烧有**绿色火焰**
- 脱水序列：$\ce{4H3BO3 -> 4HBO2 -> H2B4O7 -> 2B2O3}$

#### 3. 硼酸盐

- 基本结构单元：$\ce{BO3}$ 平面三角形和 $\ce{BO4}$ 四面体
- **硼砂**（四硼酸钠）：$\ce{Na2B4O5(OH)4·8H2O}$（习惯写作 $\ce{Na2B4O7·10H2O}$）
- 结构：四个硼原子中，两个 $\ce{BO3}$ 平面三角形和两个 $\ce{BO4}$ 四面体
- 易水解显碱性，水溶液具有缓冲作用
- 硼砂熔融态能溶解金属氧化物（与硼珠试验类似）

#### 4. 氮化硼（BN）

- 制备：$\ce{Na2B4O7 + 2NH4Cl -> 2NaCl + B2O3 + 2BN + 4H2O}$
- 结构：具有石墨型晶体结构，但不导电
- 化学式：$(\ce{BN})_x$

## 知识要点

1. 碳、硅同属 IVA 族，硼与硅处于对角线位置，有相似性
2. 碳是足电子原子，硼是缺电子原子（形成 3c-2e 多中心键）
3. 碳的同素异形体：金刚石（$sp^3$，不导电）、石墨（$sp^2$，导电，润滑）、$\ce{C60}$（$sp^{2.28}$）
4. CO 与 $\ce{N2}$ 等电子体，有还原性和配位性；$\ce{CO2}$ 为 $sp$ 杂化，酸性氧化物
5. 碳酸盐热稳定性：$\ce{H2CO3 < MHCO3 < M2CO3}$，金属离子极化力越强越不稳定
6. 硅烷比烷烃少且不稳定，$\ce{SiH4}$ 能自燃，易水解
7. $\ce{SiCl4}$ 极易水解；$\ce{H2SiF6}$ 是强酸
8. 硅氧四面体是硅酸盐的基本结构单元（链状、片状、三维网络状）
9. 硼的三个成键特征：共价性、缺电子多中心键、以 $\ce{B12}$ 二十面体为基础
10. 硼酸是一元弱酸（$K_a = 7.3 × 10^{-10}$），鉴定反应生成硼酸酯有绿色火焰
11. 硼砂易水解显碱性，有缓冲作用；硼珠试验用于鉴别金属离子
12. 氮化硼（BN）具有石墨型结构但不导电
