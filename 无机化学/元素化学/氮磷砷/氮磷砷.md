## 16.1 元素的基本性质

氮族元素位于周期表第五主族，价层电子构型 $ns^2np^3$，包括氮（N）、磷（P）、砷（As）、锑（Sb）、铋（Bi）五种元素。

### 一、基本性质

| 性质 | 趋势 |
|------|------|
| 原子半径、离子半径 | 从氮到铋逐渐增大 |
| 第一电离能、电负性 | 从氮到铋依次减小 |
| 金属性 | 从氮到铋逐渐增强 |
| 非金属性 | 从氮到铋逐渐减弱 |

**成键特征**：
- 获得 3 个电子形成氧化态 -3 的离子比 VIA 和 VIIA 困难得多，只有 $\mathrm{N^{3-}}$、$\mathrm{P^{3-}}$
- 氮族主要氧化态为 +3、+5，形成**共价化合物**是本族元素成键的特征

### 二、惰性电子对效应

VA 族自上往下，氧化值为 +3 的物质稳定性增加（还原性减弱），而氧化值为 +5 的物质稳定性降低（氧化性增强），称为"**惰性电子对效应**"。（IIIA、IVA 也存在此现象）

## 16.2 氮和氮的化合物

### 一、氮气

- 工业制备：分馏液态空气
- 实验室制备：$\mathrm{2NaNO_{2} + 2NH_{4}Cl \rightarrow N_{2}\uparrow + 2NaCl + 4H_{2}O}$

#### N 原子的成键特征和价键结构

| 结构基础 | 杂化态 | $\sigma$ 键 | $\pi$ 键 | 孤电子对 | 分子形态 | 实例 |
|----------|--------|-----------|---------|---------|---------|------|
| 共价键 $-N^{-}$ | $sp^3$ | 4 | 0 | 0 | 正四面体 | $\mathrm{NH_{4}^{+}}$ |
| | $sp^3$ | 3 | 0 | 1 | 三角锥 | $\mathrm{NF_{3}}$、$\mathrm{NH_{3}}$ |
| $-N=$ | $sp^2$ | 3 | 1 | 0 | 三角形 | $\mathrm{NO_{3}^{-}}$ |
| $N\equiv$ | $sp^2$、$sp$ | 2 | 1 | 1 | 角形 | $\mathrm{Cl-N=O}$ |
| | $sp$ | 2 | 2 | 0 | 直线形 | $[\mathrm{O-N-O}]+$ |
| | $sp$ | 1 | 2 | 1 | 直线形 | $\mathrm{N≡N}$ |
| 离子键 $\mathrm{N^{3-}}$ | — | — | — | — | — | $\mathrm{Li_{3}N}$、$\mathrm{Ca_{3}N_{2}}$、$\mathrm{Mg_{3}N_{2}}$ |
| 配位键 | — | — | — | — | — | 氨合物、胺合物、过渡金属氮分子配合物 |

### 二、氮的氢化物

#### 1. 氨

**结构**：N 采用不等性 $sp^3$ 杂化，分子呈**三角锥形**。

**制备**：$\mathrm{2NH_{4}Cl + Ca(OH)_{2} \rightarrow 2NH_{3}\uparrow + CaCl_{2} + 2H_{2}O}$

**物理性质**：
- 能溶解碱金属生成蓝色溶液：$\mathrm{Na + x(NH_{3}) \rightarrow Na^{+} + e^{-}(NH_{3})_x}$（氨合电子）
- 液氨是良好溶剂
- 液氨自偶电离：$\mathrm{2NH_{3}(l) \rightleftharpoons NH_{4}^{+} + NH_{2}^{-}}$，$K = 1.9 × 10^{-33}$（-50℃）

**化学性质**：
- **弱碱性**：$\mathrm{NH_{3} + H_{2}O \rightleftharpoons NH_{4}^{+} + OH^{-}}$
- **还原性**：
  - 纯氧中燃烧：$\mathrm{4NH_{3} + 3O_{2} \rightarrow 2N_{2}\uparrow + 6H_{2}O}$
  - Pt 催化氧化：$\mathrm{4NH_{3} + 5O_{2} \rightarrow 4NO + 6H_{2}O}$
  - 与氯气：$\mathrm{2NH_{3}(过量) + 3Cl_{2} \rightarrow N_{2} + 6HCl}$（检验 $\mathrm{Cl_{2}}$ 管道漏气）
- **加合反应**（形成配合物）：$\mathrm{Ag^{+} + 2NH_{3} \rightarrow [Ag(NH_{3})_{2}]^{+}}$
- **取代反应**：$\mathrm{2Na + 2NH_{3} \rightarrow 2NaNH_{2} + H_{2}\uparrow }$；$\mathrm{2Al + 2NH_{3} \rightarrow AlN + 3H_{2}\uparrow }$

#### 2. 铵盐
- 遇强碱并加热放出氨气：$\mathrm{NH_{4}^{+} + OH^{-} \rightarrow NH_{3}·H_{2}O}$（鉴定反应）
- 热稳定性差：
  - 生成氨和酸：$\mathrm{NH_{4}Cl \rightarrow NH_{3}\uparrow + HCl\uparrow }$（加热）
  - 氧化性酸组成的铵盐：$\mathrm{NH_{4}NO_{3} \rightarrow N_{2}O\uparrow + 2H_{2}O\uparrow }$；$\mathrm{(NH_{4})_{2}Cr_{2}O_{7} \rightarrow N_{2}\uparrow + Cr_{2}O_{3} + 4H_{2}O\uparrow }$

#### 3. 联氨（肼 $\mathrm{N_{2}H_{4}}$）
- N 以 $sp^3$ 杂化轨道形成 $\sigma$ 键
- 水溶液呈弱碱性
- 同时具有强氧化性和强还原性
- 不稳定：$\mathrm{N_{2}H_{4} \rightarrow N_{2} + 2H_{2}}$

#### 4. 羟氨（$\mathrm{NH_{2}OH}$）
- 水溶液呈弱碱性，主要用做还原剂
- 易分解：$\mathrm{3NH_{2}OH \rightarrow NH_{3}\uparrow + N_{2}\uparrow + 3H_{2}O}$

#### 5. 叠氮酸（$\mathrm{HN_{3}}$）和叠氮化物
- $\mathrm{HN_{3}}$ 中第一个 N 为 $sp^2$ 杂化，其余 N 为 $sp$ 杂化
- 水溶液呈酸性，不稳定，具有氧化还原性

### 三、氮的含氧化合物

#### 1. 氮的氧化物
氮在氧化物中的氧化态从 +I 到 +V，所有氧化物在热力学上都**不稳定**，除 $\mathrm{N_{2}O}$ 外都有毒性。

| 化学式 | 熔点 / K | 沸点 / K | 性状 |
|--------|----------|----------|------|
| $\mathrm{N_{2}O}$ | 182 | 184.5 | 无色，助燃，无毒，麻醉剂 |
| $\mathrm{NO}$ | 109.5 | 121 | 无色，顺磁性，易氧化 |
| $\mathrm{N_{2}O_{3}}$ | 172.4 | 276.5 (分解) | 低温固体，液体蓝色 |
| $\mathrm{NO_{2}}$ | 181 | 294.5 (分解) | 红棕色气体，低温聚合为 $\mathrm{N_{2}O_{4}}$ |
| $\mathrm{N_{2}O_{4}}$ | 261.9 | 297.3 | 无色气体，易离解为 $\mathrm{NO_{2}}$ |
| $\mathrm{N_{2}O_{5}}$ | 305.6 | (升华) | 固体，无色，易潮解，强氧化剂 |

**一氧化氮（NO）**：
- 制备：$\mathrm{3Cu + 8HNO_{3}(稀) \rightarrow 3Cu(NO_{3})_{2} + 2NO\uparrow + 4H_{2}O}$
- 无色气体，有毒，难溶于水
- 常温易被氧化为 $\mathrm{NO_{2}}$
- 与金属形成配合物：$\mathrm{FeSO_{4} + NO \rightarrow [Fe(NO)(H_{2}O)_{5}]SO_{4}}$
- NO 有 11 个价电子（**奇电子分子**），顺磁性，液体/固态时形成双聚合体呈反磁性

**二氧化氮（$\mathrm{NO_{2}}$）**：
- 红棕色气体，有特殊臭味，低温下生成 $\mathrm{N_{2}O_{4}}$
- $\mathrm{N_{2}O_{4}(g) \rightleftharpoons 2NO_{2}(g)}$，$\Delta_r H_m^\theta = 57\ \text{kJ/mol}$
- 不稳定（>150℃分解），以氧化性为主
- 废气处理：$\mathrm{NO + NO_{2} + 2NaOH \rightarrow 2NaNO_{2} + H_{2}O}$
- N 采取 $sp^2$ 杂化，角形，存在 $\pi_3^4$ 离域 $\pi$ 键

#### 2. 亚硝酸及其盐

- 制备：$\mathrm{NO + NO_{2} + H_{2}O \rightarrow 2HNO_{2}}$
- 除 $\mathrm{AgNO_{2}}$ 外，一般亚硝酸盐易溶于水，均有毒

**化学性质**：
- **弱酸性**：$\mathrm{HNO_{2} \rightleftharpoons H^{+} + NO_{2}^{-}}$
- **不稳定性**：$\mathrm{2HNO_{2} \rightarrow NO\uparrow (棕色) + NO_{2}\uparrow + H_{2}O}$
- **氧化还原性**：酸性介质中是强氧化剂，碱性介质中是还原剂
  - 氧化性：$\mathrm{2NO_{2}^{-} + 2I^{-} + 4H^{+} \rightarrow 2NO + I_{2} + 2H_{2}O}$（定量测定亚硝酸盐）
  - 还原性：$\mathrm{2MnO_{4}^{-} + 5NO_{2}^{-} + 6H^{+} \rightarrow 2Mn^{2+} + 5NO_{3}^{-} + 3H_{2}O}$
- $\mathrm{NO_{2}^{-}}$ 易生成配合物：$\mathrm{3K^{+} + [Co(NO_{2})_{6}]^{3-} -> K_{3}[Co(NO_{2})_{6}]↓}$（黄色，鉴定钾离子）

#### 3. 硝酸及其盐

**物理性质**：
- 纯硝酸：无色易挥发液体，密度 1.53 g·cm⁻³
- 浓硝酸：含 $\mathrm{HNO_{3}}$ 69%，密度 1.4 g·cm⁻³，~15 mol·L⁻¹
- 发烟硝酸：溶有过量 $\mathrm{NO_{2}}$ 的浓硝酸产生红烟

**化学性质**：
- **受热分解**：$\mathrm{4HNO_{3} \rightarrow 4NO_{2}\uparrow + O_{2}\uparrow + 2H_{2}O}$（光、热）
- **强酸**
- **氧化性**：
  - 非金属：$\mathrm{C + 4HNO_{3} \rightarrow CO_{2}\uparrow + 4NO_{2}\uparrow + 2H_{2}O}$
  - 金属：产物随硝酸浓度不同而不同，$\mathrm{HNO_{3}}$ 越稀，还原产物价态越低；金属越活泼，还原产物价态越低
  - 可使金属"钝化"
- **硝化作用**

**硝酸盐**：
- 大多数无色、易溶于水的离子型晶体，水溶液无氧化性
- 固体高温时分解，呈现氧化性，分解产物因金属阳离子不同而有差别

#### 4. 亚硝酸、硝酸及其盐的性质对比
- 酸性：$\mathrm{HNO_{2}}$（弱酸）、$\mathrm{HNO_{3}}$（强酸）
- 棕色环实验：鉴定 $\mathrm{NO_{3}^{-}}$，消除 $\mathrm{NO_{2}^{-}}$ 干扰用氨基磺酸或硫脲

## 16.3 磷及其化合物

### 一、单质磷

磷有多种同素异形体，主要为**白磷、红磷、黑磷**。

| 性质 | 白磷（黄磷） | 红磷 | 黑磷 |
|------|-------------|------|------|
| 颜色 | 白色蜡状，遇光变黄 | 红 | 黑 |
| 毒性 | 剧毒 | 无毒 | — |
| 化学性质 | 空气中自燃，很不稳定 | 稳定 | 最稳定，不易反应 |
| 结构 | $\mathrm{P_{4}}$ 分子 | 可能为链状 | 层状，能导电（"金属磷"） |

- 白磷中毒可用 $\mathrm{CuSO_{4}}$ 解毒：$\mathrm{2P + 5CuSO_{4} + 8H_{2}O \rightarrow 5Cu + 2H_{3}PO_{4} + 5H_{2}SO_{4}}$
- 白磷在隔绝空气、533 K 转变为红磷

### 二、磷的氢化物和卤化物

#### 1. $\mathrm{PH_{3}}$（膦）

| 性质 | $\mathrm{PH_{3}}$ | $\mathrm{NH_{3}}$ |
|------|------------|------------|
| 极性 | 小 | 大 |
| 水中溶解度 | 小 | 大 |
| 碱性 | $\mathrm{PH_{3} < NH_{3}}$ | — |
| 还原性 | $\mathrm{PH_{3} > NH_{3}}$（更强） | — |
| 水解性 | 极易 | — |

- 化学性质：$\mathrm{PH_{4}I + NaOH \rightarrow NaI + PH_{3}\uparrow + H_{2}O}$
- 还原性：$\mathrm{8CuSO_{4} + 2PH_{3} + 8H_{2}O \rightarrow 2H_{3}PO_{4} + 8H_{2}SO_{4} + 8Cu}$

#### 2. 磷的卤化物

**$\mathrm{PCl_{3}}$**：
- 结构与 $\mathrm{NH_{3}}$ 相似（三角锥）
- 制备：$\mathrm{3Cl_{2} + 2P(过量) \rightarrow 2PCl_{3}}$
- 性质：无色液体，易水解：$\mathrm{PCl_{3} + 3H_{2}O \rightarrow H_{3}PO_{3} + 3HCl}$

**$\mathrm{PCl_{5}}$**：
- 结构：三角双锥
- 制备：$\mathrm{PCl_{3} + Cl_{2}(过量) \rightarrow PCl_{5}}$
- 不稳定（160℃分解）：$\mathrm{PCl_{5} \rightarrow PCl_{3} + Cl_{2}}$
- 水解：$\mathrm{PCl_{5} + H_{2}O(不足) \rightarrow POCl_{3} + 2HCl}$；$\mathrm{PCl_{5} + H_{2}O(过量) \rightarrow H_{3}PO_{4} + 5HCl}$

### 三、磷的含氧化合物

#### 1. 磷的氧化物

**$\mathrm{P_{4}O_{6}}$**（三氧化二磷）：
- 制备：$\mathrm{P_{4} + 3O_{2}(不足) \rightarrow P_{4}O_{6}}$
- 白色蜡状固体，有毒
- 吸水性强：$\mathrm{P_{4}O_{6} + 6H_{2}O(冷) \rightarrow 4H_{3}PO_{3}}$；$\mathrm{P_{4}O_{6} + 6H_{2}O(热) \rightarrow 3H_{3}PO_{4} + PH_{3}\uparrow }$
- 具有还原性：$\mathrm{P_{4}O_{6} + 2O_{2} \rightarrow P_{4}O_{10}}$

**$\mathrm{P_{4}O_{10}}$**（五氧化二磷）：
- 制备：$\mathrm{P_{4} + 5O_{2}(充足) \rightarrow P_{4}O_{10}}$
- 极易潮解，是优良的干燥剂
- 与水反应：$\mathrm{P_{4}O_{10} + 6H_{2}O \rightarrow 4H_{3}PO_{4}}$

#### 2. 磷的含氧酸及其盐

| 名称 | 化学式 | 磷的氧化态 |
|------|--------|-----------|
| 正磷酸 | $\mathrm{H_{3}PO_{4}}$ | +V |
| 焦磷酸 | $\mathrm{H_{4}P_{2}O_{7}}$ | +V |
| 三磷酸 | $\mathrm{H_{5}P_{3}O_{10}}$ | +V |
| 偏磷酸 | $\mathrm{(HPO_{3})_n}$ | +V |
| 亚磷酸 | $\mathrm{H_{3}PO_{3}}$ | +III |
| 次磷酸 | $\mathrm{H_{3}PO_{2}}$ | +I |

**正磷酸及其盐**：
- 纯磷酸为无色晶体，不挥发的三元中强酸，因氢键呈粘稠状
- 正盐：除 $\mathrm{K^{+}}$、$\mathrm{Na^{+}}$、$\mathrm{NH_{4}^{+}}$ 盐外，一般不溶于水
- 磷酸一氢盐：同上
- 磷酸二氢盐：均溶于水
- 可溶性磷酸盐水解性：$\mathrm{Na_{3}PO_{4}}$ 强碱性，$\mathrm{Na_{2}HPO_{4}}$ 碱性，$\mathrm{NaH_{2}PO_{4}}$ 弱酸性
- $\mathrm{PO_{4}^{3-}}$ 鉴定：与过量钼酸铵在稀硝酸中生成黄色磷钼酸铵沉淀

**焦磷酸及其盐**：
- 酸性比磷酸强，在冷水中慢慢转化为磷酸
- $\mathrm{2Na_{2}HPO_{4} \rightarrow Na_{4}P_{2}O_{7} + H_{2}O}$

**亚磷酸（$\mathrm{H_{3}PO_{3}}$）**：
- 无色晶体，易溶于水
- 二元中强酸
- 具有还原性：$\mathrm{2Ag^{+} + H_{3}PO_{3} + H_{2}O \rightarrow 2Ag + H_{3}PO_{4} + 2H^{+}}$

**次磷酸（$\mathrm{H_{3}PO_{2}}$）**：
- 一元中强酸
- 具有强还原性（碱性中更强）
- 不稳定，发生歧化：$\mathrm{3H_{3}PO_{2} \rightarrow 2H_{3}PO_{3} + PH_{3}\uparrow }$

## 16.4 砷

### 一、砷化氢（胂 $\mathrm{AsH_{3}}$）

- 制备：$\mathrm{As_{2}O_{3} + 6Zn + 6H_{2}SO_{4} \rightarrow 2AsH_{3} + ZnSO_{4} + 3H_{2}O}$
- 剧毒，恶臭气体
- 化学性质：
  - 在空气中自燃：$\mathrm{2AsH_{3} + 3O_{2} \rightarrow As_{2}O_{3} + 3H_{2}O}$
  - 缺氧时受热分解：$\mathrm{2AsH_{3} \rightarrow 2As + 3H_{2}\uparrow }$（"砷镜"，马氏试砷法）
  - 还原性极强：$\mathrm{2AsH_{3} + 12AgNO_{3} + 3H_{2}O \rightarrow As_{2}O_{3} + 12HNO_{3} + 12Ag\downarrow }$（古氏试砷法）

### 二、卤化物

$\mathrm{AsX_{3}}$：熔沸点随分子量递增而递增；易水解：$\mathrm{AsCl_{3} + 3H_{2}O \rightarrow H_{3}AsO_{3} + 3HCl}$

### 三、氧化物、含氧酸及其盐

| 物质 | 颜色 | 酸碱性 |
|------|------|--------|
| $\mathrm{As_{2}O_{3}}$（砒霜） | 白色 | 两性偏酸（剧毒） |
| $\mathrm{H_{3}AsO_{3}}$ | 无色 | 弱酸性 |
| $\mathrm{As_{2}O_{5}}$ | 白色 | 酸性 |
| $\mathrm{H_{3}AsO_{4}}$ | 无色 | 中强酸 |

- $\mathrm{As_{2}O_{3}}$ 解毒：新制 $\mathrm{Fe(OH)_{2}}$ 悬浮液
- $\mathrm{As_{2}O_{3}}$ 的两性：$\mathrm{As_{2}O_{3} + 6NaOH \rightarrow 2Na_{3}AsO_{3} + 3H_{2}O}$；$\mathrm{As_{2}O_{3} + 6HCl \rightarrow 2AsCl_{3} + 3H_{2}O}$
- $\mathrm{H_{3}AsO_{3}}$：酸性介质中以氧化性为主，碱性介质中以还原性为主
- $\mathrm{H_{3}AsO_{4}}$：中强酸，具有氧化性

### 四、硫化物

| 硫化物 | 颜色 | 俗称 |
|--------|------|------|
| $\mathrm{As_{2}S_{3}}$ | 黄色 | 雌黄 |
| $\mathrm{As_{2}S_{5}}$ | 黄色 | — |
| $\mathrm{As_{4}S_{4}}$ | 橘红色 | 雄黄 |

- $\mathrm{As_{2}S_{3}}$ 两性偏酸，溶于碱或碱性硫化物生成硫代亚砷酸盐
- $\mathrm{As_{2}S_{3}}$ 在酸中不稳定：$\mathrm{2AsS_{3}^{3-} + 6H^{+} -> As_{2}S_{3}↓ + 3H_{2}S↑}$

## 知识要点

1. 氮族元素价层电子构型 $ns^2np^3$，存在惰性电子对效应（低氧化态稳定性从上到下增加）
2. 氮的成键方式多样（$sp^3$、$sp^2$、$sp$ 杂化），可形成 $\sigma$ 键、$\pi$ 键、配位键
3. 氨为三角锥形，弱碱性，有还原性和配位性
4. 硝酸是强氧化剂，还原产物随浓度降低和金属活泼性增加而价态降低
5. 亚硝酸在酸性中是强氧化剂，碱性中是还原剂
6. 磷有白磷、红磷、黑磷三种同素异形体，白磷剧毒且在空气中自燃
7. $\mathrm{P_{4}O_{10}}$ 是优良干燥剂，$\mathrm{H_{3}PO_{4}}$ 是不挥发的三元中强酸
8. 亚磷酸（$\mathrm{H_{3}PO_{3}}$）为二元酸，次磷酸（$\mathrm{H_{3}PO_{2}}$）为一元酸，均有还原性
9. 砷的化合物：$\mathrm{As_{2}O_{3}}$（砒霜）剧毒，两性偏酸；马氏试砷法和古氏试砷法
10. 磷酸盐溶解性规律：正盐（除 $\mathrm{K^{+}}$、$\mathrm{Na^{+}}$、$\mathrm{NH_{4}^{+}}$）难溶，二氢盐均溶
