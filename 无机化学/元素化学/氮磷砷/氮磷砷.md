> 主讲：王申堂 | 化学化工学院 | 第四篇 元素化学（一）非金属

## 16.1 元素的基本性质

氮族元素位于周期表第五主族，价层电子构型 $ns^2np^3$，包括氮（N）、磷（P）、砷（As）、锑（Sb）、铋（Bi）五种元素。

### 一、基本性质

| 性质 | 趋势 |
|------|------|
| 原子半径、离子半径 | 从氮到铋逐渐增大 |
| 第一电离能、电负性 | 从氮到铋依次减小 |
| 金属性 | 从氮到铋逐渐增强 |
| 非金属性 | 从氮到铋逐渐减弱 |

**成键特征**：
- 获得 3 个电子形成氧化态 -3 的离子比 VIA 和 VIIA 困难得多，只有 $\ce{N^{3-}}$、$\ce{P^{3-}}$
- 氮族主要氧化态为 +3、+5，形成**共价化合物**是本族元素成键的特征

### 二、惰性电子对效应

VA 族自上往下，氧化值为 +3 的物质稳定性增加（还原性减弱），而氧化值为 +5 的物质稳定性降低（氧化性增强），称为"**惰性电子对效应**"。（IIIA、IVA 也存在此现象）

## 16.2 氮和氮的化合物

### 一、氮气

- 工业制备：分馏液态空气
- 实验室制备：$\ce{2NaNO2 + 2NH4Cl -> N2↑ + 2NaCl + 4H2O}$

#### N 原子的成键特征和价键结构

| 结构基础 | 杂化态 | $\sigma$ 键 | $\pi$ 键 | 孤电子对 | 分子形态 | 实例 |
|----------|--------|-----------|---------|---------|---------|------|
| 共价键 $-N-$ | $sp^3$ | 4 | 0 | 0 | 正四面体 | $\ce{NH4+}$ |
| | $sp^3$ | 3 | 0 | 1 | 三角锥 | $\ce{NF3}$、$\ce{NH3}$ |
| $-N=$ | $sp^2$ | 3 | 1 | 0 | 三角形 | $\ce{NO3-}$ |
| $N\equiv$ | $sp^2$、$sp$ | 2 | 1 | 1 | 角形 | $\ce{Cl-N=O}$ |
| | $sp$ | 2 | 2 | 0 | 直线形 | $[\ce{O-N-O}]+$ |
| | $sp$ | 1 | 2 | 1 | 直线形 | $\ce{N≡N}$ |
| 离子键 $\ce{N^{3-}}$ | — | — | — | — | — | $\ce{Li3N}$、$\ce{Ca3N2}$、$\ce{Mg3N2}$ |
| 配位键 | — | — | — | — | — | 氨合物、胺合物、过渡金属氮分子配合物 |

### 二、氮的氢化物

#### 1. 氨

**结构**：N 采用不等性 $sp^3$ 杂化，分子呈**三角锥形**。

**制备**：$\ce{2NH4Cl + Ca(OH)2 -> 2NH3↑ + CaCl2 + 2H2O}$

**物理性质**：
- 能溶解碱金属生成蓝色溶液：$\ce{Na + x(NH3) -> Na+ + e-(NH3)_x}$（氨合电子）
- 液氨是良好溶剂
- 液氨自偶电离：$\ce{2NH3(l) <=> NH4+ + NH2-}$，$K = 1.9 × 10^{-33}$（-50℃）

**化学性质**：
- **弱碱性**：$\ce{NH3 + H2O <=> NH4+ + OH-}$
- **还原性**：
  - 纯氧中燃烧：$\ce{4NH3 + 3O2 -> 2N2↑ + 6H2O}$
  - Pt 催化氧化：$\ce{4NH3 + 5O2 -> 4NO + 6H2O}$
  - 与氯气：$\ce{2NH3(过量) + 3Cl2 -> N2 + 6HCl}$（检验 $\ce{Cl2}$ 管道漏气）
- **加合反应**（形成配合物）：$\ce{Ag+ + 2NH3 -> [Ag(NH3)2]+}$
- **取代反应**：$\ce{2Na + 2NH3 -> 2NaNH2 + H2↑}$；$\ce{2Al + 2NH3 -> AlN + 3H2↑}$

#### 2. 铵盐
- 遇强碱并加热放出氨气：$\ce{NH4+ + OH- -> NH3·H2O}$（鉴定反应）
- 热稳定性差：
  - 生成氨和酸：$\ce{NH4Cl -> NH3↑ + HCl↑}$（加热）
  - 氧化性酸组成的铵盐：$\ce{NH4NO3 -> N2O↑ + 2H2O↑}$；$\ce{(NH4)2Cr2O7 -> N2↑ + Cr2O3 + 4H2O↑}$

#### 3. 联氨（肼 $\ce{N2H4}$）
- N 以 $sp^3$ 杂化轨道形成 $\sigma$ 键
- 水溶液呈弱碱性
- 同时具有强氧化性和强还原性
- 不稳定：$\ce{N2H4 -> N2 + 2H2}$

#### 4. 羟氨（$\ce{NH2OH}$）
- 水溶液呈弱碱性，主要用做还原剂
- 易分解：$\ce{3NH2OH -> NH3↑ + N2↑ + 3H2O}$

#### 5. 叠氮酸（$\ce{HN3}$）和叠氮化物
- $\ce{HN3}$ 中第一个 N 为 $sp^2$ 杂化，其余 N 为 $sp$ 杂化
- 水溶液呈酸性，不稳定，具有氧化还原性

### 三、氮的含氧化合物

#### 1. 氮的氧化物
氮在氧化物中的氧化态从 +I 到 +V，所有氧化物在热力学上都**不稳定**，除 $\ce{N2O}$ 外都有毒性。

| 化学式 | 熔点 / K | 沸点 / K | 性状 |
|--------|----------|----------|------|
| $\ce{N2O}$ | 182 | 184.5 | 无色，助燃，无毒，麻醉剂 |
| $\ce{NO}$ | 109.5 | 121 | 无色，顺磁性，易氧化 |
| $\ce{N2O3}$ | 172.4 | 276.5 (分解) | 低温固体，液体蓝色 |
| $\ce{NO2}$ | 181 | 294.5 (分解) | 红棕色气体，低温聚合为 $\ce{N2O4}$ |
| $\ce{N2O4}$ | 261.9 | 297.3 | 无色气体，易离解为 $\ce{NO2}$ |
| $\ce{N2O5}$ | 305.6 | (升华) | 固体，无色，易潮解，强氧化剂 |

**一氧化氮（NO）**：
- 制备：$\ce{3Cu + 8HNO3(稀) -> 3Cu(NO3)2 + 2NO↑ + 4H2O}$
- 无色气体，有毒，难溶于水
- 常温易被氧化为 $\ce{NO2}$
- 与金属形成配合物：$\ce{FeSO4 + NO -> [Fe(NO)(H2O)5]SO4}$
- NO 有 11 个价电子（**奇电子分子**），顺磁性，液体/固态时形成双聚合体呈反磁性

**二氧化氮（$\ce{NO2}$）**：
- 红棕色气体，有特殊臭味，低温下生成 $\ce{N2O4}$
- $\ce{N2O4(g) <=> 2NO2(g)}$，$\Delta_r H_m^\theta = 57\ \text{kJ/mol}$
- 不稳定（>150℃分解），以氧化性为主
- 废气处理：$\ce{NO + NO2 + 2NaOH -> 2NaNO2 + H2O}$
- N 采取 $sp^2$ 杂化，角形，存在 $\pi_3^4$ 离域 $\pi$ 键

#### 2. 亚硝酸及其盐

- 制备：$\ce{NO + NO2 + H2O -> 2HNO2}$
- 除 $\ce{AgNO2}$ 外，一般亚硝酸盐易溶于水，均有毒

**化学性质**：
- **弱酸性**：$\ce{HNO2 <=> H+ + NO2-}$
- **不稳定性**：$\ce{2HNO2 -> NO↑(棕色) + NO2↑ + H2O}$
- **氧化还原性**：酸性介质中是强氧化剂，碱性介质中是还原剂
  - 氧化性：$\ce{2NO2- + 2I- + 4H+ -> 2NO + I2 + 2H2O}$（定量测定亚硝酸盐）
  - 还原性：$\ce{2MnO4- + 5NO2- + 6H+ -> 2Mn^{2+} + 5NO3- + 3H2O}$
- $\ce{NO2-}$ 易生成配合物：$\ce{3K+ + [Co(NO2)6]^{3-} -> K3[Co(NO2)6]↓}$（黄色，鉴定钾离子）

#### 3. 硝酸及其盐

**物理性质**：
- 纯硝酸：无色易挥发液体，密度 1.53 g·cm⁻³
- 浓硝酸：含 $\ce{HNO3}$ 69%，密度 1.4 g·cm⁻³，~15 mol·L⁻¹
- 发烟硝酸：溶有过量 $\ce{NO2}$ 的浓硝酸产生红烟

**化学性质**：
- **受热分解**：$\ce{4HNO3 -> 4NO2↑ + O2↑ + 2H2O}$（光、热）
- **强酸**
- **氧化性**：
  - 非金属：$\ce{C + 4HNO3 -> CO2↑ + 4NO2↑ + 2H2O}$
  - 金属：产物随硝酸浓度不同而不同，$\ce{HNO3}$ 越稀，还原产物价态越低；金属越活泼，还原产物价态越低
  - 可使金属"钝化"
- **硝化作用**

**硝酸盐**：
- 大多数无色、易溶于水的离子型晶体，水溶液无氧化性
- 固体高温时分解，呈现氧化性，分解产物因金属阳离子不同而有差别

#### 4. 亚硝酸、硝酸及其盐的性质对比
- 酸性：$\ce{HNO2}$（弱酸）、$\ce{HNO3}$（强酸）
- 棕色环实验：鉴定 $\ce{NO3-}$，消除 $\ce{NO2-}$ 干扰用氨基磺酸或硫脲

## 16.3 磷及其化合物

### 一、单质磷

磷有多种同素异形体，主要为**白磷、红磷、黑磷**。

| 性质 | 白磷（黄磷） | 红磷 | 黑磷 |
|------|-------------|------|------|
| 颜色 | 白色蜡状，遇光变黄 | 红 | 黑 |
| 毒性 | 剧毒 | 无毒 | — |
| 化学性质 | 空气中自燃，很不稳定 | 稳定 | 最稳定，不易反应 |
| 结构 | $\ce{P4}$ 分子 | 可能为链状 | 层状，能导电（"金属磷"） |

- 白磷中毒可用 $\ce{CuSO4}$ 解毒：$\ce{2P + 5CuSO4 + 8H2O -> 5Cu + 2H3PO4 + 5H2SO4}$
- 白磷在隔绝空气、533 K 转变为红磷

### 二、磷的氢化物和卤化物

#### 1. $\ce{PH3}$（膦）

| 性质 | $\ce{PH3}$ | $\ce{NH3}$ |
|------|------------|------------|
| 极性 | 小 | 大 |
| 水中溶解度 | 小 | 大 |
| 碱性 | $\ce{PH3 < NH3}$ | — |
| 还原性 | $\ce{PH3 > NH3}$（更强） | — |
| 水解性 | 极易 | — |

- 化学性质：$\ce{PH4I + NaOH -> NaI + PH3↑ + H2O}$
- 还原性：$\ce{8CuSO4 + 2PH3 + 8H2O -> 2H3PO4 + 8H2SO4 + 8Cu}$

#### 2. 磷的卤化物

**$\ce{PCl3}$**：
- 结构与 $\ce{NH3}$ 相似（三角锥）
- 制备：$\ce{3Cl2 + 2P(过量) -> 2PCl3}$
- 性质：无色液体，易水解：$\ce{PCl3 + 3H2O -> H3PO3 + 3HCl}$

**$\ce{PCl5}$**：
- 结构：三角双锥
- 制备：$\ce{PCl3 + Cl2(过量) -> PCl5}$
- 不稳定（160℃分解）：$\ce{PCl5 -> PCl3 + Cl2}$
- 水解：$\ce{PCl5 + H2O(不足) -> POCl3 + 2HCl}$；$\ce{PCl5 + H2O(过量) -> H3PO4 + 5HCl}$

### 三、磷的含氧化合物

#### 1. 磷的氧化物

**$\ce{P4O6}$**（三氧化二磷）：
- 制备：$\ce{P4 + 3O2(不足) -> P4O6}$
- 白色蜡状固体，有毒
- 吸水性强：$\ce{P4O6 + 6H2O(冷) -> 4H3PO3}$；$\ce{P4O6 + 6H2O(热) -> 3H3PO4 + PH3↑}$
- 具有还原性：$\ce{P4O6 + 2O2 -> P4O10}$

**$\ce{P4O10}$**（五氧化二磷）：
- 制备：$\ce{P4 + 5O2(充足) -> P4O10}$
- 极易潮解，是优良的干燥剂
- 与水反应：$\ce{P4O10 + 6H2O -> 4H3PO4}$

#### 2. 磷的含氧酸及其盐

| 名称 | 化学式 | 磷的氧化态 |
|------|--------|-----------|
| 正磷酸 | $\ce{H3PO4}$ | +V |
| 焦磷酸 | $\ce{H4P2O7}$ | +V |
| 三磷酸 | $\ce{H5P3O10}$ | +V |
| 偏磷酸 | $\ce{(HPO3)_n}$ | +V |
| 亚磷酸 | $\ce{H3PO3}$ | +III |
| 次磷酸 | $\ce{H3PO2}$ | +I |

**正磷酸及其盐**：
- 纯磷酸为无色晶体，不挥发的三元中强酸，因氢键呈粘稠状
- 正盐：除 $\ce{K+}$、$\ce{Na+}$、$\ce{NH4+}$ 盐外，一般不溶于水
- 磷酸一氢盐：同上
- 磷酸二氢盐：均溶于水
- 可溶性磷酸盐水解性：$\ce{Na3PO4}$ 强碱性，$\ce{Na2HPO4}$ 碱性，$\ce{NaH2PO4}$ 弱酸性
- $\ce{PO4^{3-}}$ 鉴定：与过量钼酸铵在稀硝酸中生成黄色磷钼酸铵沉淀

**焦磷酸及其盐**：
- 酸性比磷酸强，在冷水中慢慢转化为磷酸
- $\ce{2Na2HPO4 -> Na4P2O7 + H2O}$

**亚磷酸（$\ce{H3PO3}$）**：
- 无色晶体，易溶于水
- 二元中强酸
- 具有还原性：$\ce{2Ag+ + H3PO3 + H2O -> 2Ag + H3PO4 + 2H+}$

**次磷酸（$\ce{H3PO2}$）**：
- 一元中强酸
- 具有强还原性（碱性中更强）
- 不稳定，发生歧化：$\ce{3H3PO2 -> 2H3PO3 + PH3↑}$

## 16.4 砷

### 一、砷化氢（胂 $\ce{AsH3}$）

- 制备：$\ce{As2O3 + 6Zn + 6H2SO4 -> 2AsH3 + ZnSO4 + 3H2O}$
- 剧毒，恶臭气体
- 化学性质：
  - 在空气中自燃：$\ce{2AsH3 + 3O2 -> As2O3 + 3H2O}$
  - 缺氧时受热分解：$\ce{2AsH3 -> 2As + 3H2↑}$（"砷镜"，马氏试砷法）
  - 还原性极强：$\ce{2AsH3 + 12AgNO3 + 3H2O -> As2O3 + 12HNO3 + 12Ag↓}$（古氏试砷法）

### 二、卤化物

$\ce{AsX3}$：熔沸点随分子量递增而递增；易水解：$\ce{AsCl3 + 3H2O -> H3AsO3 + 3HCl}$

### 三、氧化物、含氧酸及其盐

| 物质 | 颜色 | 酸碱性 |
|------|------|--------|
| $\ce{As2O3}$（砒霜） | 白色 | 两性偏酸（剧毒） |
| $\ce{H3AsO3}$ | 无色 | 弱酸性 |
| $\ce{As2O5}$ | 白色 | 酸性 |
| $\ce{H3AsO4}$ | 无色 | 中强酸 |

- $\ce{As2O3}$ 解毒：新制 $\ce{Fe(OH)2}$ 悬浮液
- $\ce{As2O3}$ 的两性：$\ce{As2O3 + 6NaOH -> 2Na3AsO3 + 3H2O}$；$\ce{As2O3 + 6HCl -> 2AsCl3 + 3H2O}$
- $\ce{H3AsO3}$：酸性介质中以氧化性为主，碱性介质中以还原性为主
- $\ce{H3AsO4}$：中强酸，具有氧化性

### 四、硫化物

| 硫化物 | 颜色 | 俗称 |
|--------|------|------|
| $\ce{As2S3}$ | 黄色 | 雌黄 |
| $\ce{As2S5}$ | 黄色 | — |
| $\ce{As4S4}$ | 橘红色 | 雄黄 |

- $\ce{As2S3}$ 两性偏酸，溶于碱或碱性硫化物生成硫代亚砷酸盐
- $\ce{As2S3}$ 在酸中不稳定：$\ce{2AsS3^{3-} + 6H+ -> As2S3↓ + 3H2S↑}$

## 知识要点

1. 氮族元素价层电子构型 $ns^2np^3$，存在惰性电子对效应（低氧化态稳定性从上到下增加）
2. 氮的成键方式多样（$sp^3$、$sp^2$、$sp$ 杂化），可形成 $\sigma$ 键、$\pi$ 键、配位键
3. 氨为三角锥形，弱碱性，有还原性和配位性
4. 硝酸是强氧化剂，还原产物随浓度降低和金属活泼性增加而价态降低
5. 亚硝酸在酸性中是强氧化剂，碱性中是还原剂
6. 磷有白磷、红磷、黑磷三种同素异形体，白磷剧毒且在空气中自燃
7. $\ce{P4O10}$ 是优良干燥剂，$\ce{H3PO4}$ 是不挥发的三元中强酸
8. 亚磷酸（$\ce{H3PO3}$）为二元酸，次磷酸（$\ce{H3PO2}$）为一元酸，均有还原性
9. 砷的化合物：$\ce{As2O3}$（砒霜）剧毒，两性偏酸；马氏试砷法和古氏试砷法
10. 磷酸盐溶解性规律：正盐（除 $\ce{K+}$、$\ce{Na+}$、$\ce{NH4+}$）难溶，二氢盐均溶
