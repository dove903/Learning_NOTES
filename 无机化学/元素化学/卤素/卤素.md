## 14.1 卤素的通性

### 一、元素基本性质

卤素位于周期表第七主族，价层电子构型为 $ns^2np^5$，包括 F、Cl、Br、I、At 五种元素。

| 性质 | F | Cl | Br | I |
|------|---|----|----|---|
| 价电子构型 | $2s^22p^5$ | $3s^23p^5$ | $4s^24p^5$ | $5s^25p^5$ |
| 常见氧化态 | -I, 0 | -I, 0, I, III, V, VII | -I, 0, I, III, V, VII | -I, 0, I, III, V, VII |
| 共价半径 / pm | 64 | 99 | 114.2 | 133.3 |
| 电负性 | 3.98 | 3.16 | 2.96 | 2.66 |
| 电离能 / (kJ·mol⁻¹) | 1681 | 1251 | 1140 | 1008 |

**主要变化规律**：
- 从上到下，原子半径、离子半径增大
- 第一电离能和电负性从 F → I 依次减小
- 氧化性：$\varphi^\theta(\ce{X2/X-})$ 值从 F → I 逐渐减小
- 氧化值：F（-1，0）；Cl、Br、I（-1，0，+1，+3，+5，+7）
- 电负性越大，该元素单质及高氧化态物种氧化性越强

### 二、卤素的存在

卤素以 $\ce{X-}$ 负一价离子的形式存在于矿石和海水中：
- **F**：萤石 $\ce{CaF2}$、冰晶石 $\ce{Na3AlF6}$、氟磷灰石 $\ce{Ca5F(PO4)3}$
- **Cl**：海水、盐湖、钾石盐 KCl、光卤石 $\ce{KCl·MgCl2·6H2O}$
- **Br**：主要存在于海水中
- **I**：主要被海藻吸收
- **At**：放射性元素，人工合成

### 三、卤素的电势图

- **氧化性较强的物种**：能发生歧化反应的物种有 $\ce{HClO2}$、$\ce{ClO3-}$ 等

## 14.2 卤素单质

### 一、卤素单质的物理性质

卤素单质均为双原子分子（$\ce{X2}$）：

| 性质 | $\ce{F2}$ | $\ce{Cl2}$ | $\ce{Br2}$ | $\ce{I2}$ |
|------|-----------|------------|------------|-----------|
| 室温聚集态 | 气 | 气 | 液 | 固 |
| 颜色 | 浅黄 | 黄绿 | 红棕 | 紫黑 |
| 沸点 / ℃ | -188 | -34.5 | 59 | 183 |
| 熔点 / ℃ | -220 | -101 | -7.3 | 113 |

- 熔沸点、密度等依次增大
- 颜色依次加深
- 较难溶于水，溴和碘易溶于有机溶剂（$\ce{CCl4}$ 中 $\ce{I2}$ 为紫色，$\ce{Br2}$ 从黄到红棕色）
- 碘在 $\ce{KI}$ 中溶解度增大

### 二、卤素单质的化学性质

卤素单质最突出的化学性质是**氧化性**：
$$\text{氧化能力：}\ \ce{F2 > Cl2 > Br2 > I2}$$

#### 1. 置换反应
前面的卤素单质可以从后面的卤素卤化物中置换出卤素单质：
$$\ce{Cl2 + 2KBr -> Br2 + 2KCl}$$
$$\ce{Cl2 + 2KI -> I2 + 2KCl}$$

#### 2. 与单质的反应
- **与金属**：$\ce{2Fe + 3F2 -> 2FeF3}$、$\ce{Sn + 2Br2 -> SnBr4}$
- **与非金属**：$\ce{2P + 3Cl2 -> 2PCl3}$、$\ce{2P + 5Cl2 -> 2PCl5}$、$\ce{X2 + H2 -> 2HX}$

#### 3. 与水的反应
$$\ce{2X2 + 2H2O -> 4H+ + 4X- + O2↑}$$
$\ce{F2}$、$\ce{Cl2}$、$\ce{Br2}$ 能与水发生氧化反应，而 $\ce{I2}$ 不能。
$$\ce{4I- + O2 + 4H+ -> 2I2 + 2H2O}$$

#### 4. 歧化反应
$$\ce{X2 + H2O -> H+ + X- + HXO}$$
歧化程度：$\ce{Cl2 > Br2 > I2}$
$$\ce{K(Br2) = 7.2 × 10^{-9}},\quad \ce{K(I2) = 2.0 × 10^{-13}}$$

**碱性条件下的歧化反应**：
$$\ce{X2 + 2OH- -> X- + XO- + H2O}$$
$$\ce{3X2 + 6OH- -> 5X- + XO3- + 3H2O}$$
$$\ce{3XO- -> 2X- + XO3-}$$

| 条件 | $\ce{Cl2}$ | $\ce{Br2}$ | $\ce{I2}$ |
|------|------------|------------|-----------|
| 常温 | $\ce{ClO-}$ | $\ce{BrO3-}$ | $\ce{IO3-}$ |
| 加热 | $\ce{ClO3-}$ | $\ce{BrO3-}$ | $\ce{IO3-}$ |
| 低温 | $\ce{ClO-}$ | $\ce{BrO-}$ (0℃) | $\ce{IO3-}$ |
| pH范围 | pH > 4 | pH > 6 | pH > 9 |

稳定性：$\ce{ClO- > BrO- > IO-}$

#### 5. 氟与碱反应的特殊性
碱溶液较稀 (2%) 时：
$$\ce{2F2 + 2OH- -> 2F- + OF2 + 2H2O}$$
碱溶液较浓时：
$$\ce{2F2 + 4OH- -> 4F- + O2 + 2H2O}$$

### 三、卤素的制备和用途

制备可归结为卤素负离子的氧化，还原能力：$\ce{I- > Br- > Cl- > F-}$

#### 1. 氟的制备
- **电解法（1886年）**：$2\ce{KHF2} \xrightarrow{\text{电解}} 2\ce{KF} + \ce{H2↑} + \ce{F2↑}$
- **化学法（1986年）**：$2\ce{K2MnF6} + 4\ce{SbF5} \xrightarrow{432\ \ce{K}} 4\ce{KSbF6} + 2\ce{MnF3} + \ce{F2↑}$

#### 2. 氯的制备
- **电解法**：$\ce{2NaCl + 2H2O -> 2NaOH + H2↑ + Cl2↑}$
- **氧化法**：$\ce{MnO2 + 4HCl(浓) -> MnCl2 + Cl2↑ + 2H2O}$

#### 3. 溴的制备（置换反应）
$$\ce{2Br- + Cl2 -> Br2 + 2Cl-}$$

#### 4. 碘的制备
$$\ce{2I- + Cl2 -> I2 + 2Cl-}$$
以碘酸钠为原料：$\ce{2IO3- + 5HSO3- -> 5SO4^{2-} + H2O + 3H+ + I2}$

**用途**：氟→制冷剂、杀虫剂、灭火剂；氯→合成 HCl、漂白粉；溴→汽油抗震剂、催泪毒剂；碘→消毒剂、碘酒。

## 14.3 氟氯溴碘的化合物

### 一、卤化氢和氢卤酸

#### 1. 物理性质
- 无色气体，有刺激味
- 极易溶于水，在空气中与水蒸气形成白色酸雾
- 熔沸点依 $\ce{HCl-HBr-HI}$ 有规律变化，但 $\ce{HF}$ 例外

#### 2. 化学性质

**酸性**：$\ce{HF << HCl < HBr < HI}$
| 性质 | $\ce{HF}$ | $\ce{HCl}$ | $\ce{HBr}$ | $\ce{HI}$ |
|------|-----------|------------|------------|-----------|
| $K_a$ | $10^{-4}$ | $10^{3}$ | $10^{10}$ | $10^{11}$ |

$\ce{HF}$ 在浓度为 5~15 mol/L 时变为强酸（缔合所致）：
$$\ce{HF <=> H+ + F-}\quad K_a = 7.2 × 10^{-4}$$
$$\ce{2HF <=> H+ + HF2-}\quad K_a = 5.1$$

**还原性**：$\ce{HI > HBr > HCl > HF}$

**热稳定性**：$\ce{HF > HCl > HBr > HI}$

| 性质 | $\ce{HF}$ | $\ce{HCl}$ | $\ce{HBr}$ | $\ce{HI}$ |
|------|-----------|------------|------------|-----------|
| $\Delta_f H^\theta$ / kJ·mol⁻¹ | -271 | -92.3 | -36.4 | 26.5 |

从 $\ce{HF → HI}$：酸性增强，还原性增强，稳定性下降。

#### 3. HF 的特殊性
- 与 $\ce{SiO2}$ 反应：$\ce{SiO2 + 4HF -> SiF4↑ + 2H2O}$
- 与硅酸盐反应：$\ce{CaSiO3 + 6HF -> CaF2 + SiF4↑ + 3H2O}$
- 解毒方法：$\ce{MgO}$ + 甘油涂之

#### 4. 制备方法
1. 直接合成：制 $\ce{HCl}$
2. 复分解反应：制 $\ce{HF}$、$\ce{HCl}$
3. 非金属卤化物的水解：制 $\ce{HBr}$、$\ce{HI}$
4. 碳氢化物的卤化：制 $\ce{HCl}$

### 软硬酸碱规则

| 类型 | 定义 | 实例 |
|------|------|------|
| **硬酸** | 正电荷高、体积小、变形性低 | $\ce{Li+}$、$\ce{Mg^{2+}}$、$\ce{Al^{3+}}$ |
| **软酸** | 正电荷低（或为0）、体积大、变形性高 | $\ce{Cu+}$、$\ce{Ag+}$、$\ce{Au+}$ |
| **硬碱** | 变形性小、电负性大 | $\ce{F-}$、$\ce{OH-}$ |
| **软碱** | 变形性大、电负性小 | $\ce{I-}$、$\ce{S^{2-}}$ |

"**硬亲硬，软亲软，软硬交界就不管**"

### $\ce{Cl-}$、$\ce{Br-}$、$\ce{I-}$ 的鉴定

| 离子 | 沉淀反应 | 现象 |
|------|----------|------|
| $\ce{Cl-}$ | $\ce{Ag+ + Cl- -> AgCl↓}$ | 白色沉淀，溶于氨水 |
| $\ce{Br-}$ | $\ce{Ag+ + Br- -> AgBr↓}$ | 淡黄色沉淀，微溶于浓氨水；加氯水 + $\ce{CCl4}$ 显红棕色 |
| $\ce{I-}$ | $\ce{Ag+ + I- -> AgI↓}$ | 黄色沉淀；加氯水 + $\ce{CCl4}$ 显紫色；遇淀粉显蓝色 |

### 二、卤化物、卤素互化物、多卤化物

#### 1. 卤化物
- **离子型卤化物**：卤素与 IA、IIA 族元素形成的化合物
- **共价型卤化物**：卤素与非金属、高氧化值金属形成的化合物

#### 离子极化理论

**极化力**（使其他离子极化的能力）：电荷越多、半径越小、极化力越强。
- 电荷：$\ce{Al^{3+} > Mg^{2+} > Na+}$
- 半径：$\ce{Mg^{2+} > Ba^{2+}}$
- 电子构型：18、18+2、2 电子构型 > 9-17 电子构型 > 8 电子构型

**变形性**（在电场中外层电子发生相对位移的能力）：
- 半径越大，变形性越大
- 电荷代数值越小（越负），变形性越大
- 电子构型：18、18+2、9-17 > 8 > 2

#### 卤化物键型变化的一般规律

**（1）同周期元素**：从左向右，离子型 → 共价型，熔沸点下降
例：$\ce{NaCl (bp 1465℃) > MgCl2 (1412℃) > AlCl3 (升华 181℃) > SiCl4 (57.6℃)}$

**（2）p 区同族元素**：从上往下，共价型 → 离子型，熔沸点增大
例：$\ce{NF3 < PF3}$

**（3）同一金属不同卤化物**：从 $\ce{F-}$ 至 $\ce{I-}$ 共价成分增大，熔沸点下降
例：$\ce{AlF3 (1272℃) > AlCl3 (181℃) > AlBr3 (253℃) > AlI3 (382℃)}$

**（4）同一金属不同氧化值**：氧化值越高，共价成分越大，熔沸点越低
例：$\ce{SnCl2 (mp 247℃) > SnCl4 (mp -33℃)}$

#### 溶解性变化规律
- 大多数卤化物溶于水，$\ce{AgX}$、$\ce{PbX2}$、$\ce{Hg2X2}$、$\ce{CuX}$ 难溶
- 氟化物特殊性：$\ce{CaF2}$ 难溶而其他 $\ce{CaX2}$ 易溶
- 重金属卤化物溶解性：$\ce{MF_n > MCl_n > MBr_n > MI_n}$
- 例：$\ce{AgF}$ 易溶；$\ce{AgCl}$、$\ce{AgBr}$、$\ce{AgI}$ 溶解度依次减小

#### 2. 卤素互化物
- 定义：不同卤素原子之间的共价化合物 $\ce{XX'_n}$
- 中心原子 X：电负性小的重卤素（如 I）
- 配体 X'：电负性大的轻卤素（如 F）
- 配位数 n 多为奇数
- 例：$\ce{IF7}$、$\ce{BrF5}$、$\ce{ClF3}$、$\ce{ICl3}$
- 绝大多数不稳定，熔沸点低，能做氧化剂，能水解

#### 3. 多卤化物
- 定义：金属卤化物与卤素单质或卤素互化物的加合物
- 例：$\ce{KI3}$、$\ce{KICl2}$、$\ce{KI2Cl}$、$\ce{KIBrCl}$
- 含 3 个卤原子的多卤化物阴离子：空间构型几乎都是**直线型**

### 三、拟卤素

定义：某些 -1 价离子在形成化合物时与卤化物相似，自由状态时原子团性质也与卤素单质相似。

常见拟卤离子：$\ce{CN-}$、$\ce{SCN-}$、$\ce{OCN-}$、$\ce{ONC-}$、$\ce{NCN-}$、$\ce{N3-}$

### 四、卤素氧化物和含氧酸及其盐

#### 1. 卤素的氧化物

| 元素 | 氧化物 | 重要氧化物 | 构型 |
|------|--------|------------|------|
| F | $\ce{OF2, O2F2}$ | $\ce{OF2}$ | 角形 |
| Cl | $\ce{Cl2O, ClO2, Cl2O6, Cl2O7}$ | $\ce{Cl2O, ClO2}$ | 角形 |
| Br | $\ce{Br2O, BrO2, BrO3, Br3O8}$ | 对热均不稳定 | — |
| I | $\ce{I2O4, I2O5, I2O7}$ 等 | $\ce{I2O5}$ | 白色固体 |

- $\ce{Cl2O}$：$\ce{Cl2O + H2O -> 2HOCl}$，是 $\ce{HOCl}$ 的酸酐
- $\ce{I2O5}$：$\ce{2HIO3 -> I2O5 + H2O}$，可氧化 $\ce{CO}$：$\ce{I2O5 + 5CO -> I2 + 5CO2}$（鉴定 CO）

#### 2. 卤素的含氧酸

| 名称 | 氧化值 | F | Cl | Br | I |
|------|--------|---|----|----|---|
| 次卤酸 | +1 | $\ce{HOF}$ | $\ce{HOCl}$* | $\ce{HBrO}$* | $\ce{HOI}$* |
| 亚卤酸 | +3 | — | $\ce{HClO2}$* | $\ce{HBrO2}$* | — |
| 卤酸 | +5 | — | $\ce{HClO3}$* | $\ce{HBrO3}$* | $\ce{HIO3}$ |
| 高卤酸 | +7 | — | $\ce{HClO4}$ | $\ce{HBrO4}$* | $\ce{HIO4}$、$\ce{H5IO6}$ |

*表示仅存在于溶液中，不能分离出纯酸

**酸根离子结构**：

| 名称 | 杂化类型 | 空间构型 |
|------|----------|----------|
| 次卤酸根离子 | $sp^3$（不等性） | 直线型 |
| 亚卤酸根离子 | $sp^3$（不等性） | V 型 |
| 卤酸根离子 | $sp^3$（不等性） | 三角锥 |
| 高卤酸根离子 | $sp^3$ | 正四面体 |
| $\ce{IO6^{5-}}$ 离子 | $sp^3d^2$ | 正八面体 |

**（1）次卤酸及其盐**
- 酸性：$\ce{HOCl > HOBr > HOI}$（$K_a$ 分别为 $2.8×10^{-8}$、$2.6×10^{-9}$、$2.4×10^{-11}$）
- 稳定性：$\ce{HOCl > HOBr > HOI}$
- $\ce{XO-}$ 歧化：$\ce{3HXO -> 3H+ + 2X- + XO3-}$
- $\ce{HClO}$：很弱的酸（比碳酸还弱），不稳定，是强氧化剂
- 漂白粉：$\ce{2Cl2 + 3Ca(OH)2 -> Ca(OCl)2·CaCl2·Ca(OH)2·2H2O}$

**（2）亚卤酸及其盐**
- 仅亚氯酸 $\ce{HClO2}$，中强酸，不稳定，其盐较稳定，具有氧化性

**（3）卤酸及其盐**
- 酸性：$\ce{HClO3 > HBrO3 > HIO3}$
- 稳定性：$\ce{HClO3 < HBrO3 < HIO3}$
- 氧化性：$\ce{HClO3 < HBrO3 > HIO3}$（体现了 p 区第四周期元素的不规律性）
- $\ce{KClO3}$：火柴头中的氧化剂

**（4）高卤酸及其盐**
- 酸性：$\ce{HClO4 > HBrO4 > H5IO6}$
- 稳定性：$\ce{HBrO4 < HClO4 < H5IO6}$
- 氧化性：$\ce{HClO4 < HBrO4 > H5IO6}$
- $\ce{HClO4}$：稀溶液较稳定，浓溶液不稳定，受热分解
- $\ce{H5IO6}$：强氧化剂，可测定 $\ce{Mn^{2+}}$
- $\ce{NH4ClO4}$：现代火箭推进剂

#### 含氧氯酸及其盐的性质规律

| 趋势 | 说明 |
|------|------|
| 热稳定性 | $\ce{HClO < HClO2 < HClO3 < HClO4}$ 递增 |
| 酸性 | $\ce{HClO < HClO2 < HClO3 < HClO4}$ 递增 |
| 氧化性 | $\ce{HClO > HClO2 > HClO3 > HClO4}$ 递减 |

## 知识要点

1. 卤素价层电子构型 $ns^2np^5$，从上到下原子半径增大、电负性减小、氧化性减弱
2. 卤素单质均为双原子分子，熔沸点、密度、颜色依次递增
3. 氧化能力：$\ce{F2 > Cl2 > Br2 > I2}$，可发生置换、与单质、与水、歧化等反应
4. 卤化氢酸性：$\ce{HF << HCl < HBr < HI}$；还原性：$\ce{HI > HBr > HCl > HF}$；稳定性：$\ce{HF > HCl > HBr > HI}$
5. $\ce{HF}$ 的特殊性：腐蚀玻璃、有毒、缔合增强酸性
6. 软硬酸碱规则："硬亲硬，软亲软"
7. 卤化物键型变化规律：同周期从左向右共价性增强；同族从上向下离子性增强
8. 卤素含氧酸酸性：$\ce{HClO4}$ 最强；氧化性：次卤酸最强，高卤酸最弱
9. 氯的含氧酸稳定性：随氧化数升高而增强
10. 拟卤素（$\ce{CN-}$、$\ce{SCN-}$ 等）性质与卤素相似
